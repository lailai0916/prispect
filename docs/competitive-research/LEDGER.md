## 本轮发现并修复的问题

- 同采集组不等于相同正文：公开模型载荷仅按实际完整可用文本去重，不丢掉同组不同反方文本；来源关系中的独立性仍未知。
- 公告快照时间不能当作节选读取时间：无 readAt 保持未知，单列快照时点。
- JSON/CSV 保留原件没有公网 URL 时，实验室错误暂停全部事实：改为从本账号保存报告 snapshot 绑定同主体、有效哈希的保留上传原件，依旧检查范围/摘录；不得伪造公开 URL。
- 说法类型切换后的动态 Select 项目索引错位：固定目标顺序，保留原话并显式禁用不适用目标，不自动改成其他目标。
- 已知现金路径无日末缺口与未知有区别；导出和版本差异同时保留付款优先保守缺口、时序敏感性与反求状态。非 PDF 来源页不称 PDF 页。
- 已有付款上限但拟付款超限时，下一步改为“核对拟付款与自设暴露条件”；不暗示补资料或自动抬高上限。主页面先呈当前阻塞和下一步，再呈角色与原话依据。
