# 可核验演示路线与运行方式

演示价值是“这个字段来自哪里、为什么停止、改一个条件会怎样”，不是保证企业可靠。三类内容始终明确：公开企业真实请求、人工录入的合成演练、离线保存版本。真实请求失败时保留错误与覆盖，不偷偷换成成功fixture。

## 启动改进版本

在当前工作区运行：

```sh
cd /workspace/prispect-improve
npm ci
npm run build
PORT=4320 APP_ORIGIN=http://127.0.0.1:4320 CASHLENS_DATA_DIR=/tmp/prispect-demo-state npm start
```

使用空白的演示目录可避免接触原用户资料；已有目录应继续保留，不删除。默认 `npm start` 使用4317。登录自己的账号后，材料、事项和导出均归本账号。模型未配置仍可以使用规则、原件核对、版本、反求和本地练习；界面不宣称模型研究完成。迁移到另一目录时调整上面的绝对工作区路径。

## 6分钟核心演示

1. **说明任务与范围（30秒）**：从“付款与交接”进入一笔明确标记的合成预付款。经营名义是品牌，合同、收款、退款责任分别列出；相同名称也不证明关系。不必先伪造企业年报或当前现金。
2. **财务信号到具体询证（60秒）**：导入下列合成年度原件，预览后主动确认，2025净利100000、经营现金60000、现金利润比60%。查看精确现金桥与原件；回款/库存有竞争解释。明确60%不是销售回款率，更不是可信概率。可以从关联财务问题继续到当前事项。
3. **原话与字段依据（60秒）**：摘录“付款可退”“集团上市”“首付锁定交付”，分别选择实际退款、签约主体、条款目标。显示来源文本定位或未知；点击原件与材料。字段匹配不证明原话真实、责任关系、条款效力或实际履行。
4. **不同材料阶段与条件反求（60秒）**：总额100000、已付10000、实际交付0、实退款0、自设上限20000。输入反求上限10000；仅有三项金额原件时，记录反求因缺主体/条款暂停。主动补入三个角色及条款原件后，记录路径也得到10000。总额/上限仍是人工条件，不能因此批准付款。A新增20000敞口30000，B新增5000敞口15000。
5. **撤回与恢复（60秒）**：撤回已付款原件，记录方案与反求暂停，输入假设仍保留；“本版改变了什么”列出材料、门槛及计算差异。恢复后记录结果回来。另加同范围不同金额，撤回反证仍有已知冲突。过去版本只读，恢复是新版本。
6. **参与及离线核验（60秒）**：在证据实验室的可选练习中先预测撤回库存调整会影响哪些路径，查看4条实际暂停且60%比值仍保留，恢复并复盘。练习不保存grade/采用。导出当前事项HTML预览，断网打开仍看到该版摘录、条件与差异；原件未打包，联网时需本账号复核。
7. **深入追问（30秒）**：展示现金接手案例同日日末为正但付款优先存在缺口；显示真正的未知、当前规则重算、source-located有限字段检查与账户权限边界。不要把这些计算叫预测或付款推荐。

## 可手工导入的原始演练资料

这些文件是合成输入，不是真实企业原件；`.json-upload`保留验证字节，便于复核。为界面选择文件时复制为普通`.json`文件，内容不变：

```sh
mkdir -p /tmp/prispect-demo-inputs
cp docs/competitive-research/evidence/prispect-before/synthetic-original.json-upload /tmp/prispect-demo-inputs/annual-synthetic.json
cp docs/competitive-research/evidence/prispect-before/complete-records.json-upload /tmp/prispect-demo-inputs/payment-records-synthetic.json
cp docs/competitive-research/evidence/prispect-after/roles-and-terms.json-upload /tmp/prispect-demo-inputs/roles-terms-synthetic.json
```

实际上传/保存接口重新计算保留文件的字节SHA；文件内声明的占位SHA不是原件认证。预览时确认公司、年度、币种、合并范围和摘录，再采用。主动创建事项，字段与材料关联都可以由评委亲自操作。没有后台注入真实账户或自动采用；一键生成完整合成案卷仍属于清单里的后续增强。

## 公开研究的诚实演示

正常provider从300893/2025开始，展示匹配候选及实际请求。当前环境本轮官方重新解析失败，未形成assessment，错误和页面保留在 `evidence/prispect-after/live-company-receipt.json`。已有公开信息可以展开来源关系、日期、实际读取范围和有限研究框架；标题、摘要、正文节选不混同。

研究目录的 `public-fixture-server.mjs` 是独立工程验收服务。它用明示合成公司、零模型调用的提供商验证报告、来源表、模板和打印，必须保留fixture标识；不能拿它作为成功联网研究、竞品胜负或真实企业结论。现场依赖失败时，可以继续上述合成原件/私有规则路线，明确其材料类型与无联网依赖部分。
