# 剩余价值、验证边界与下一步

所有发现均保留在241项结构化清单和全量索引。实施状态不是功能计数：existing表示已有覆盖，部分转化的实施只覆盖写明的absorbed_scope；原竞品机制的剩余部分不能由共同测试名代替验收。待办的具体ID、前置与动作由values逐项维护。

## 本轮不能完成的外部验证

- **真实公共查询**：正常provider对300893/2025在目录后官方重新解析失败。没有用成功合成页替代请求，没有换公司/年份。要复验需可用的官方来源网络，再从同代码/年份和冷缓存重做主体、PDF、规则、公开判断及反方链；沿用请求/时间/覆盖预算。
- **真实模型**：没有有权使用的已配置外部模型服务。规则失败/引用/白名单由受控接口测试覆盖，但实际模型稳定性、成本、叙事质量和反证收敛尚未验证。配置合法服务后先用公共合成/真实已读短原文测试；不得为了模型验收发私有付款或完整文件。
- **真实用户效果**：没有招募用户，不宣称耗时、点击、理解、留存、学习或付费的提升已测。下一步让初次使用者用相同材料完成原话核对、原件查找、证据撤回、付款比较和依赖复盘，记录错读/完成/时间。自动检查只证明行为约束。
- **现场及跨浏览器**：本轮桌面、320/375/390窄屏使用Linux Chromium，不是Safari/Firefox/实体手机或辅助技术测试。现场用实际设备和网络重走核心路线；离线冷启动完整应用、浏览器缓存策略和灾难恢复不能由已加载页面零请求推断。
