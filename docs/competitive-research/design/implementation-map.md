公司公开研究、采用原件的财报核查、账号内付款/接手事项沿用三类既有数据边界；新增机制都从这条路径进入。每项发现的完整去向见 [241 项索引](../VALUE-INDEX.md)及 `values/*.json`。表中的 ID 是组合代表，不替代全量记录；涉及 deferred ID 时仅说明已提炼的相关部分，完整增强仍按该项待办，不能把组合表当作全项实现证明。

## 程序负责的约束

新私有字段都是向后兼容可选输入；schema检查长度、目标集合、目的兼容和重复ID。原件、材料与版本仍通过owner会话/CSRF/baseRevision。接口不调用模型，材料与私人说法不进入公共 Agent。所有计算采用整数分，未知不填零，已知冲突不会因撤回反证消失。

新增来源元数据只逐字段选择公开字段，局部关系ID明确不能作模型引用；原有可引用 evidence IDs 与校验仍是权威。旧按采集cluster丢弃不同正文的缺陷已修为实际完整可用文本相等才去重，前4000字相同但后段不同也保留。哈希不认证原件；公告没有读取时刻时不拿快照时刻代填。

## 最终阅读顺序与打磨取舍

实际截图显示新增说法卡会把原有阻断项推得过远，因此下一步页改为：紧凑版本差异/事项说明 → 当前阻断与具体行动 → 各责任角色 → 原话和依据 → 可选历史线索。所有资料仍可查，不能为简洁隐藏未知。付款反求先给结果与依据分支，再展开公式及金额；窄屏是同一单列逻辑。学习反馈先给实际暂停/用户所选路径，再给独立保留项；内容与计算不改。

各改进保留析光原有几何logo、主题令牌、普通文档层次、中英文术语与减少动态设置。数额中性，状态紧凑且有文字；未引入游戏头像、绿色可付结论、任意确信度或多套阅读模式。

## 仍需后续工作的价值

暂缓不是遗漏。所有 deferred 项记录前置与下一步，见全量索引；可能需要授权POI/工商/法律事件、曾用名官方证据、片段枚举模型契约、可审计的长期来源版本、通用幂等键、真实取消/单飞服务延迟验证或真人任务比较。已有覆盖与未落地增强分别写明。禁止把未运行的增强改为verified，也不能因未取得合法服务而写成竞品没有实现。
