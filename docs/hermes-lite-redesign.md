# Lite：以 Hermes 架构为主的对照改造

用户最终要求是全面吸收 Hermes / ReLoad 的结构、交互和动效优点，融入现有析光；最新明确采用蓝白科技配色，允许与参考站同类颜色，减少长金额和冗余上屏内容。Pro 与 Lite 的数据源和分析结果一致，展示和操作路径分别设计。此前八个软件的研究保留为背景，游戏不参与改造。

## 参考范围

公开源码固定于 `SecrificeYuan/Hermes-Company-Analyzer` 的 `abd78e65e15686b1acd6491b24879b5458e16747`。本轮实际浏览正式网站的首页、搜索、真实候选与筛选入口；原报告前端在隔离环境运行它自己的离线案例，不配置模型、不调用其报告后端。源码版本与实时部署版本不混同。

本轮 19 张已检视截图、固定源码位置和完整边界保存在 ignored `output/reference-review/hermes-focused-20261004/`。两张候选未到达／入场未完成的早期截图已明确弃用，并分别以实际候选到达和完整报告入场后的截图替代。

## 同任务对照与落实

| 对照任务   | Hermes 值得吸收的结构                  | 析光 Lite 的独立实现                                                   |
| ---------- | -------------------------------------- | ---------------------------------------------------------------------- |
| 开始研究   | 单任务中心输入、清楚的意图选择         | 集中真实公司搜索；历史样例和阅读路径各自有原生页面链接                 |
| 确认公司   | 贴近输入的名称／代码候选、键盘操作     | 复用真实匹配与候选确认，保留年度、IME、取消和所属账号隔离              |
| 继续阅读   | 直接可见的最近记录                     | 使用当前账号／访客的真实报告；空状态不填案例                           |
| 理解结果   | 主结论先于详细模块、短卡与紧凑信息层级 | 简短概览、紧凑元信息与有源指标；详细内容进入对应读页                   |
| 看数字     | 图表、单位与就近解释                   | 明确约数与单位的短显示；同轴金额共用刻度，精确到分的原值仍可核对       |
| 查依据     | 每张判断卡定向进入自己的证据           | 指标 ID 与同代来源精确关联；来源页、反向引用、本地分页均只读已取得材料 |
| 继续判断   | 解释后接问题或行动                     | 展示该保存报告自己的行动、缺口与追问；规则备用问题不冒称 AI 生成       |
| 切换与动效 | 短入场、分层卡片、背景网格和粒子       | 原创有界动效；四个真正独立读页，原生历史、触屏和减少动态支持           |
| 视觉一致性 | 同一套玻璃面板和清楚的对比             | 自主深蓝、亮蓝、白色，只用一个装饰重点色；数据图的系列颜色保留其意义   |

Hermes 的报告七项导航实际是长页锚点，首页三个意图也是同一页的本地模式。析光的 `page=overview|numbers|sources|questions` 来自用户明确的逐页要求，不声称原站已有这四条独立路由。每页可自然滚动，不劫持滚轮，也不照搬固定视口双列内滚。

用户随后明确认可原有「财务、公开事项、口碑线索、原文」四个样例展示的结构；保留左侧编辑式引导、右侧玻璃舞台、标签和步骤、数字对照与原文预览。其他 Lite 页面沿该蓝白玻璃视觉延伸。补充的逐字入场、卡片分层、短标签转场、指针高光和原生详情揭示只影响呈现，保持减少动态、隐藏页面暂停、即时可读文字与不变的财务金额。

## 内容与数据边界

缩写仅用于阅读展示，并标明约数。精确金额、来源、期间、口径、研究与保存代次不改；未取得与冲突数据仍明确保留。完整分析、行动、改判条件和全部引用能在相应页面查看，并从任意读页完整打印。

参考仓库没有确认整体许可证；本轮独立实现设计思路，没有搬入其源码、角色、品牌或素材。没有加入无实际后台的筛选、行情承诺或模拟研究进度。
