# Lite：以 Hermes 架构为主的对照改造

用户最终要求是全面吸收 Hermes / ReLoad 的结构、交互和动效优点，融入现有析光；最新明确采用蓝白科技配色，允许与参考站同类颜色，减少长金额和冗余上屏内容。Pro 与 Lite 的数据源和分析结果一致，展示和操作路径分别设计。此前八个软件的研究保留为背景，游戏不参与改造。

## 参考范围

公开源码固定于 `SecrificeYuan/Hermes-Company-Analyzer` 的 `abd78e65e15686b1acd6491b24879b5458e16747`。本轮实际浏览正式网站的首页、搜索、真实候选与筛选入口；原报告前端在隔离环境运行它自己的离线案例，不配置模型、不调用其报告后端。源码版本与实时部署版本不混同。

本轮 19 张已检视截图、固定源码位置和完整边界保存在 ignored `output/reference-review/hermes-focused-20261004/`。两张候选未到达／入场未完成的早期截图已明确弃用，并分别以实际候选到达和完整报告入场后的截图替代。

## 同任务对照与落实

| 对照任务   | Hermes 值得吸收的结构                  | 析光 Lite 的独立实现                                                   |
| ---------- | -------------------------------------- | ---------------------------------------------------------------------- |
| 开始研究   | 单任务中心输入、清楚的意图选择         | 集中真实公司搜索；查公司、读样例、阅读路径以三个紧凑原生链接进入       |
| 确认公司   | 贴近输入的名称／代码候选、键盘操作     | 复用真实匹配与候选确认，保留年度、IME、取消和所属账号隔离              |
| 继续阅读   | 直接可见的最近记录                     | 使用当前账号／访客的真实报告；空状态不填案例                           |
| 理解结果   | 主结论先于详细模块、短卡与紧凑信息层级 | 企业自己的财务、公开事项、口碑线索和原文四页；真实内容通过原生详情展开 |
| 看数字     | 图表、单位与就近解释                   | 明确约数与单位的短显示；同轴金额共用刻度，精确到分的原值仍可核对       |
| 查依据     | 每张判断卡定向进入自己的证据           | 指标 ID 与同代来源精确关联；来源页、反向引用、本地分页均只读已取得材料 |
| 继续判断   | 解释后接问题或行动                     | 展示该保存报告自己的行动、缺口与追问；规则备用问题不冒称 AI 生成       |
| 切换与动效 | 短入场、分层卡片、背景网格和粒子       | 原创有界动效；四个真正独立读页，原生历史、触屏和减少动态支持           |
| 视觉一致性 | 同一套玻璃面板和清楚的对比             | 自主深蓝、亮蓝、白色，只用一个装饰重点色；数据图的系列颜色保留其意义   |

Hermes 的报告七项导航实际是长页锚点，首页三个意图也是同一页的本地模式。析光的 `page=finance|public|reputation|original` 来自用户明确的逐页要求和认可的四通道展示，不声称原站已有这四条独立路由。未指定页时进入财务；旧 `overview`／`numbers` 映射为财务，`sources` 映射为原文，`questions` 映射为口碑线索，对应旧章节锚点继续兼容。每页可自然滚动并展开详情，不劫持滚轮，也不照搬固定视口双列内滚。

用户随后明确认可原有「财务、公开事项、口碑线索、原文」四个样例展示的结构；保留左侧编辑式引导、右侧玻璃舞台、标签和步骤、数字对照与原文预览。最新范围将这套结构用于每一家真实企业的四个原生阅读页，各页直接消费当前拥有者的保存研究资料。首页三个入口压缩为紧凑导航，保留真实搜索、年度、最近报告和手机点击面积。补充的逐字入场、卡片分层、短标签转场、指针高光和原生详情揭示只影响呈现，保持减少动态、隐藏页面暂停、即时可读文字与不变的财务金额。

## 内容与数据边界

缩写仅用于阅读展示，并标明约数。精确金额、来源、期间、拥有研究与保存代次不改；翻页、展开与 Lite／Pro 切换不调用来源或模型。Lite 原生翻页保留所选利润口径，Pro 保留原有默认值和口径控件，不承诺跨体验同步显示口径。判断和引用绑定自己的保存报告及来源代次，保留旧报告时注明其原快照和生成日期。完整分析、行动、改判条件和全部引用能通过原生详情查看，并从任意读页完整打印。

公开事项来自该企业已取得的公告；口碑线索来自它已保存的媒体和公众讨论记录，标题、摘要与节选按实际读取范围区分，观点及转载不转成已证实事实或独立佐证。原文页打开这家企业自己的真实来源链接、字段出处和已有节选；没有 PDF、页码或全文就如实说明。松原安全第 190／191 页裁图只属于历史样例，不进入其他企业的真实结果。四通道不新增生成数据，也不把未取得内容填成示范事件。

参考仓库没有确认整体许可证；本轮独立实现设计思路，没有搬入其源码、角色、品牌或素材。没有加入无实际后台的筛选、行情承诺或模拟研究进度。
