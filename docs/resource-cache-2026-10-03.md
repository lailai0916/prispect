# 研究资源复用 · 2026-10-03

本轮在已有账号研究复用与浏览器公开快照之上，减少重复的公开请求、PDF 解析、同行读取与成功问答。页面继续使用已有报告和来源入口；仅为解释挑战增加简短的“重新补查”操作。

除解释挑战与原有保存研究外，上述新增资源缓存均为进程内存。服务器重启或重新发布后重新预热；没有新增磁盘缓存目录、修改上传 TTL、备份留存或生产清理范围。字节上限是各层计量口径，并非整个 JavaScript 进程峰值内存保证。

公共缓存不包含账号、私人上传、付款计划、问答或工作区内容。助手缓存独立按账号隔离；缓存键是哈希，不输出问题或凭据。已删除研究必须先通过拥有者检查，重建同 ID 也不能沿用旧对象的回答。历史报告、评级和已采用原件保持原有含义。

## 时间、计数与完整性

- 命中缓存保留实际取得时间、响应哈希、报价时间和原答案生成时间。多个来源组合时，来源各自保留日期；同行样本使用其原始取得日期。
- `PublicCompanyReader.requests` 只计算真正发起的 HTTP 请求。工具调用仍是实际执行的工具操作；复用不增加独立来源、置信度或伪造处理步骤。
- 相同公共请求共享读取；一个调用者取消不影响其他仍在等待的调用者。全部取消终止上游；失败和迟到结果不能发布。
- 完整同行缓存未命中时，直接重新读取各表，避免旧的错误 HTTP 200 结果冒充完整样本。每家公司都重新检查自身分类与成员资格，均值、中位数、缺失和有效样本重新计算。
- 手动刷新传播到公开资料、综合研究、同行和挑战，绕过旧来源响应、同行快照及旧正文节选。PDF 重新下载后仍检查新字节；完全相同字节可以复用解析。
- 对话影响问题含义。连续两次相同文字但前文不同，不保证命中同一个回答；只有问题、前文及资料版本都相同才复用。
