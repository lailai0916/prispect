# 需求与验收总清单

本清单合并本会话逐次补充的要求。用户的新引导扩展现有任务，不把之前的工作自动丢弃；变更范围以最新明确要求为准。状态必须有对应运行或文件证据，代码存在不能代替公网完成。以下为本轮整合过程中的记录。
