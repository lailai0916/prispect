# 析光：数据链路与核查边界

本文交接当前实现的数据来源、计算与解释边界。金额一致、引用存在或工具运行成功，都不等于材料鉴真、企业可靠或付款获准。

整数分保证换算与运算精确，不把千元／万元列示的原表升级为精确到分的披露；来源单位与列示精度仍须保留。

## 从公开来源到两种具体核查

| 组合线索       | 已采用材料可在现金桥闭合后组合两期利润／现金方向和应收／存货调整，或识别正利润与负经营现金并存；每项触发金额附原件引用、竞争解释及两种使用视角的下一项核查材料。具体取舍见[队友原型审查](xray-agent-integration.md)。                     | 组合只提出问题，不给企业打安全分或推断造假；撤回任一所需金额、口径冲突或桥不闭合时撤回依赖它的组合。未触发不代表安全。                                                      |

## 第三方网页历史字段与原件对照

新企业查询的 `market-data` 分支返回可选 `agent.financialContext`，合同见 [`shared/company-market.ts`](../shared/company-market.ts)，沿用现有账号隔离的企业查询接口。该分支独立于 PDF 提取和模型解释，不增加用户输入，也不要求配置东方财富账户、API Key 或 Cookie。

对支持的沪深证券代码，取数请求指向 `https://datacenter.eastmoney.com/securities/api/data/v1/get` 的 `RPT_F10_FINANCE_GINCOME`、`RPT_F10_FINANCE_GCASHFLOW`、`RPT_F10_FINANCE_GBALANCE`。三次 GET 共享单次查询累计来源预算和两个公开请求许可，不保证同时完成；每表只取按报告期倒序的第一页，最多 60 行，每次限 10 秒和 2,000,000 字节。剩余来源预算不足三次时不发起这一组请求，没有翻页、样例替代或自动借用其他公司。

仅接收主体代码和机构标识相符、`ORG_TYPE=通用`、人民币、12 月 31 日年报的记录。表名的 `G` 是行业表区分，不能据此证明合并口径；金融、未确认行业及不支持的交易所保留不支持状态，不混入通用表。实际取得的年度最多保留请求年及以前最近六个，按年升序显示；不保证连续六年或一定取得请求年。

| 保存字段                                 | 接口原字段与表                                                               |
| ---------------------------------------- | ---------------------------------------------------------------------------- |
| 营业总收入 `revenue`、净利润 `netProfit` | 利润表 `TOTAL_OPERATE_INCOME`、`NETPROFIT`，均为接口字段                     |
| 经营／投资／筹资现金净额                 | 现金流量表 `NETCASH_OPERATE`、`NETCASH_INVEST`、`NETCASH_FINANCE`            |
| 货币资金、短期借款、一年内到期非流动负债 | 资产负债表 `MONETARYFUNDS`、`SHORT_LOAN`、`NONCURRENT_LIAB_1YEAR`            |
| 应收账款、存货、总资产、总负债           | 资产负债表 `ACCOUNTS_RECE`、`INVENTORY`、`TOTAL_ASSETS`、`TOTAL_LIABILITIES` |

金额先保留 JSON 数字原文，再转为人民币元的两位小数字符串；科学计数法也不经过浮点金额运算。不能精确表示到分的字段、缺值和无效值保留 `null`，不补零、不四舍五入。每年保留报告期、各表来源 ID、各自提供的披露／更新日期；抓取时间另记。利润表与现金流量表的 `NETPROFIT` 不一致时，该年的利润与经营现金字段停止比较并置为未知；缺少任一表的交叉核对字段另示未核对，不推断合并范围。

每表记录 `available|empty|failed|unsupported`、请求链接、抓取时间、可取得的响应 SHA-256 和固定错误码。哈希属于当次响应字节，不是保存的 PDF 原件或认证；重新打开接口可能取得修订后的数据。限流、访问限制、超时、格式错误和单表失败不被记为成功空结果，其他可用表可保留为 `partial`。机构标识冲突停止所有表间金额组合；同表同年重复金额冲突只撤该表该年度字段。网页取数失败本身不替换或撤销另行取得的官方 PDF。

[`CompanyFinancialTrends`](../src/CompanyFinancialTrends.tsx) 提供三组历史视图：同尺度的净利润与经营现金；年度对齐、各自金额尺度的营业总收入与净利润；货币资金与两项负债合计。最后一项只在短期借款与一年内到期非流动负债均有值时相加，不称全部短债，也不计算覆盖率或当前缺口。图表区分零、负数、缺项和缺年；选中柱或年度可查看精确原数、字段、日期、响应记录与来源链接。

净利润／经营现金可与保存的 PDF 候选逐项比金额，但须满足主体、证券代码／交易所、同年度、年报合并、人民币和候选检查通过；结果仅为金额一致、不一致或未核对，并可跳到实际保存的原件页。金额一致不认证材料、不自动采用网页指标，不解除规则报告的冲突。货币资金仍是历史字段，不会代填接任时当前可用现金。

## 竞争解释与核查动作的材料依赖

应收／库存解释分别保留历史财务信号和区分材料状态。区分材料须为当前交易主体、场景基准日期的有效来源记录，且适用字段在绑定的保存文本中定位；转录、对方陈述与假设不能替代。材料可供核对、已撤回、范围不符、冲突、未定位、仅线索及缺材料分开显示，附真实记录／来源依赖；新增、撤回和恢复形成版本并改变下一核查。可核对不等于证实原因，不鉴真，也不会补现金或使缺少历史依据的归因恢复。

内部延期条款参与来源／范围核查，但字段已定位仍不能证明同意和未来履行，门槛保持未知，下一步转为核对已有条款与影响。外部自设上限缺失转到用户输入；实际付款／交付／退款记录缺失另列，不重复索取已有依据。已知同范围字段冲突保留，撤反证或恢复旧输入不能清除。

## 权限、版本与模型边界

[`company-routes.ts`](../server/company-routes.ts)、[`decision-routes.ts`](../server/decision-routes.ts) 和 `WorkspaceStore` 将材料、任务、原件、公开查询断点与决定版本隔离到当前账号；写请求受会话、CSRF 与 Origin 校验。新账号为空，重置不预装样例。用户确认候选或标记完成，不认证材料真实性。

决定更新以 `baseRevision` 防覆盖；撤回、恢复和适用主体／日期更正均生成新版本。旧输入回放与当前已知冲突区分，恢复旧版本不能洗掉后来的反证；仍被版本引用的材料与报告不能直接删除。财报任务保留输入快照；人为排除指标不从剩余文本暗中补回，也不发给解释模型。

公开企业 Agent 只向模型发送所查询公司的公开元数据、候选页与已读短原文；私人交易记录、现金计划、跟进备注和账号数据不进入该载荷。财报任务的 [`explainWithModel`](../server/model.ts) 自动尝试已配置模型，仅发送已采用的本期与比较年度合并指标、短摘录、规则结论及非管理层解释的规则分析；不发送整份文件或未采用、排除、冲突观测。未配置模型、资料不足、冲突或调用失败时保留真实规则结果及状态。前端的 [`parseCashPlanImport`](../shared/cash-plan-import.ts) 在本地解析 CSV／JSON，确认后只是计划条件，不自动生成来源记录。

公开进度 DTO 的 `version` 保持 `langgraph-v1`。新查询私有断点范围另用 `langgraph-v2-market`，汇总等待新增网页字段分支；可恢复的旧 `langgraph-v1` 断点按原图继续，不新增该分支、屏障或网页预算。未知断点版本拒绝恢复；旧完成查询缺少 `financialContext` 时展示未保存，不补造历史取数或哈希。

## 工程承诺如何核对

开发中的分工和交叉审查、运行时的多分支编排是两件事。运行分支共享公开证据与模型配置；开发审查也不能保证所有参与者使用不同模型、完全无历史上下文。因此本项目不宣称独立金融审计或叙述完全无误。可复核的保证来自金额写入路径、类型与范围验证、原件、逐行求和和反例测试；模型仍可能选错线索，提取规则仍需更多发行人验证。参考项目的公式、覆盖、速度与测试计数不属于本项目证据，公式取舍另见[参考数据审查](reference-data-review.md)。
