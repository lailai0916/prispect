## 来源与适用边界

企业金额以官方完整报告、附注及公告原件为主，保留主体、年度、币种、单位、合并范围和页码；聚合接口可作线索，不能替代原件口径。历史集团年报不证明今天某个合同主体的余额、退款、支付能力或合作安全性。私有合同、余额和日期计划由用户提供，不能从公开数据补造。

## 可吸收的三点

1. **原始输入与公式同屏。**本项目已具备原件、哈希、页码、短摘录和确定性复算。继续让结论显示必要输入与精确金额；出处可点击不等于语义已认证。
2. **缺口对应下一材料。**已有unknown/conflict与证据撤回，已完善缺口材料指引，说明缺什么、哪段结论暂停、下一份材料是什么。公共研究不能替代银行余额、具体合同、实际退款或日期义务。
3. **公告覆盖与折叠。**当前仅提供公告折叠与覆盖计数，尚无自动事件归组，本轮不新增。后续若按主体、事件、日期归组，需保留更正和后续进展的来源链。标题用于选择先读的正文，不把标题条数转成风险概率。
