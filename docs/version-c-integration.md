## 当前导航整理（2026-10-03）

企业导航由七个专题合并为四个工作页面：**研究报告 → 财务分析／资料与来源 → 原件核查**。研究报告先给判断、评级、证据实验与下一步；财务分析包含历史走势、完整数据、行业对比和原件字段对照；资料与来源包含新闻讨论、公告、公司及股东资料、覆盖和来源比对；原件核查保留候选确认、编辑与采用。新建研究与研究库是主入口，材料、付款与交接、财报核查及核查比较归入核查工具。旧专题深链接继续定位到合并后的对应内容。

下列首次融合的功能映射和验收记录保留各自的历史范围；其中的七页导航和旧阅读视角不代表当前入口结构。本次只调整页面组织，不改变已保存记录、评级规则、取数预算或私有工作流。

## 数据与工程边界

`shared/company-workspace.ts` 定义扩展快照和轻量企业记录；`shared/company-analysis.ts` 使用整数分复算合计与比率。网页原始数值保留到源字段可表达的分，并保留响应 SHA256；这不证明原披露精确到分。来源比对超过容差时保留双方数值，但冲突字段不参与概览或问答推断。容差为一万元与主金额百万分之一中较大者，不等同于原件核验。

概览读取预算独立于 A 的 LangGraph：90 秒、最多 50 次公开请求，每次有期限与流式体积限制。高关注公告最多六份，每份 8 MB，共享 45 秒摘录期限，仅从前三页选择片段；未取得片段仍保留原文链接。行业读取也有独立 90 秒/50 次预算，要求同年度完整分页；不能用截断样本输出平均。行业分类是查询时的数据方分类，不证明历史分类恒定。

来源主体、人民币币种或组织冲突会停止相关财务组合。金融机构不套通用行业方法。短债分项缺失保持未知；货币资金不是当前可用现金。财务费用参考倍数明确使用财务费用代理，不再称为纯利息保障倍数。网页字段不会自动成为原件候选或确认材料。

扩展 API 均位于现有登录、账号归属、来源校验和 CSRF 中间件之后。刷新作业去重，避免被重复点击启动多份取数；工作区重置检查扩展作业，原件删除期间阻止删除正在刷新的记录。后台更新检查运行归属及修订，问答检查回答期间快照是否更换。侧边栏使用轻量 `/api/company-records`，不反复传输年报预览和整份公开快照。

公司匹配的 `/api/companies/directory` 与 `/api/companies/search` 保留登录校验，提前到私有工作区加载之前，只使用公开主体元数据。目录快照包含来源、获取时间和原响应哈希，24 小时后后台更新，失败保留旧目录；目录缺失仍可使用远程查询。远程候选五分钟缓存、成功空结果十五秒缓存，错误不冒充空结果；同词请求合并，最后一个等待者离开才取消上游。搜索预算为一次、3.5 秒，与后续原件取数和深度研究预算独立。此实现依据 B 已记录的本地匹配方式重新实现，未直接搬用未取得的 B 源码。

## 公司研究 Agent 与分析评级（2026-10-02）

公开快照完成后自动运行公司研究 Agent，允许用户指定最多 1,000 字研究目标。Grok 兼容的真实工具调用可读取最多六个年度财务、同年度同行、已取得公告档案、公司主题新闻，以及已知公告 ID 对应的官方 PDF 摘录。研究规划最多三轮、八次工具执行，记录真实步骤与失败；新闻/PDF 补查最多十二次请求、六件 PDF，研究阶段 120 秒。行业读取与最终分析使用各自预算，不能把这些数字解释成全流程总请求数或总耗时。详见[研究流程与方法](company-research-agent.md)。

最终报告给出盈利、现金、偿付、营运、同行、事件六维判断，以及有来源的优势、风险、后续核查和判断变化条件。析光分析评级采用四个核心财务维度等权规则，任一维度低于 40 分时整体评级最高 C，两项以上最高 D；缺失或冲突的必要字段暂不评级。AI 不修改规则分数和评级，金额通过已验证指标代入，标题不直接认定不利事实。

公开研究与企业问答只使用公开字段白名单，不发送私有付款决定、现金计划、上传预览、备注或账户资料。手动研究每账号每小时最多十二次，缓存不重复调用。并发请求去重，公开快照更新或记录删除后旧结果不能发布；失败和重启保留上一份报告的资料时间。研究与最终分析的失败、修复也计入实际模型调用次数。

这次新增功能的工具协议、模型分析、规则评级和 API 测试与真实公开数据验收分开记录，见[公司研究 Agent 验收](company-research-agent-acceptance-2026-10-02.md)；模拟模型成功不等于真实 Grok 调用成功。下面此前验收记录保持各自的历史范围。

## 企业问答入口调整

企业问答从侧边栏独立页面移到全站右下角圆形助手，点击后展开统一对话框。无需选择功能或公司：明确提到的已研究公司优先，其次沿用当前页面、上轮对话或最近研究；有歧义时通过对话追问。公司、使用方法和政策问题使用同一输入框，文档知识直接读取当前六篇正式文档的内容或摘要。规则回答、模型失败回落、引用与随企业保存的回答保留；登录后的新回答使用已配置的服务端模型，按需进行有限公开补查，不更改历史评级。

未登录时，助手检索产品文档，不调用外部模型或初始化私人工作区。登录后的产品问题可基于正式文档调用模型；无已研究公司时通过对话说明如何开始。对话与草稿仅存当前页面内存，账号切换时清空并取消请求；不会读取其他账号的企业记录，也不把产品帮助当作已保存的企业回答。

旧客户端提交的 `useModel=false` 或缺省值统一规范为 `true`。旧企业查询断点仅允许将 `false` 或缺省值升级为 `true`，保留已完成节点及累计请求预算；历史完成记录不重写。
