# Lite 与 Pro：两个完整研究体验

本轮按用户选定的第二套黑白方案实现 Lite，并沿用现有专业方案作为 Pro。两版分别设计入口、导航和研究结果的阅读动线，共用同一套账号、研究记录、公开证据与计算。

发布基线为线上 `896e079`（恢复原专业入口、报告和常驻侧栏）。Pro 查询页、报告页、侧栏、专业样式和阅读状态沿用该基线；本轮新增 Lite 路由与版本切换，并为缓存阅读补上禁止自动采集同行数据的保护。正常 Pro 研究流程继续沿用既有行为。

## 路由与阅读动线

| 入口                             | 体验                                                             |
| -------------------------------- | ---------------------------------------------------------------- |
| `/`                              | Lite 首页：巨型文字、纸张雕塑、黑白版面与真实企业查询。          |
| `/company?run=…&experience=lite` | Lite 结果：摘要 → 数字 → 来源 → 问题，四个可直接定位的阅读章节。 |
| `/query`                         | Pro 企业确认与年度选择。                                         |
| `/company?run=…`                 | Pro 研究报告，以及既有的七个 F 数据目的地。                      |
| `/?view=story`                   | 保留原滚动证据介绍。                                             |

Lite 的查询沿用既有主体匹配、候选确认、年度选择、取消、所有权隔离与 `reuseExisting` 语义；它在提交后进入独立的 Lite 结果页面。Pro 保留报告、财务走势、行业对比、披露线索、扩展核查、数据覆盖和来源比对。

企业页上的 Lite／Pro 切换保留同一条 `run`。切换只改变前端呈现，不创建研究、不刷新来源、不启动模型，也不把 Lite 当成新的服务端研究模式。已有后台研究按其真实状态继续运行。没有当前研究时，两版分别回到自己的入口。

## 视觉与动效

Lite 使用选定第二稿的黑白方向：大字入场与错位滚动、纸张雕塑的指针响应与视差、证据页的层次转场、内容揭示、全屏大字菜单和悬停／聚焦换图。动效通过已有 GSAP、CSS 与本地展示素材完成，不复制参考站的源码或素材。

当前环境中的选定方案源图为 `/workspace/generated_images/exec-b1e23036-727c-4556-9fc6-36d59c0b3f17.png`。它是视觉参考，不是金融来源或可交互验收证据。用户提供的参考包括 `https://www.jiejoe.com/home`、`https://qier.asia` 及两个 IP 站点；本轮未能重新实时访问这些站点，因此不声称逐项复现其实际动效。

装饰动效只管理呈现，不触发研究、不模拟加载或完成，也不把财务金额做成计数动画。保留原生滚动、键盘和触屏操作；减少动态偏好提供静态阅读。Pro 的专业数据页与既有图表语义继续保留。

本轮细节打磨增加了章节回看、深链接定位、失败后重新读取、未匹配主体说明，以及 AI 报告尚未完成时已取得字段来源的直接入口。首页示例填入与 URL 查询按账号和查询范围隔离；错误文字随语言切换更新。磁吸按钮在禁用或移出后可复位，容器布局变化会刷新滚动动效定位。窄屏保留顶栏控制、44px 主要点击区域和章节导航的可访问名称；这些布局调整仍待浏览器实测。

## 同一份事实与上下文

Lite 四个章节读取当前拥有者的真实研究与已保存报告：摘要展示可用判断及实际进度，数字保留选定年度、口径与精确金额，来源打开已有证据，问题接续统一助手。没有匹配主体或年度、字段缺失、来源冲突、模型未配置及任务失败均保留其实际状态，不用展示样例代替查询结果。

Lite 与 Pro 共用既有 API、缓存、整数分计算和财务规则；既有来源覆盖、刷新、重试、私有资料边界和访客／账号隔离不因体验变化而改变。历史示例始终保留其公司、年度与来源，不充当当前公司判断。

报告推荐问题沿用同一套提交语义，绑定拥有者的 `run`、年度、显示的利润口径和已保存报告 generation。普通助手建议仍只填入可编辑草稿。体验切换不能借用其他账号或更新后的报告版本重新解释旧问题。
