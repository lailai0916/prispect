# Lite 与 Pro：两个完整研究体验

用户最新明确以 Hermes / ReLoad 为 Lite 的主要设计基准，覆盖视觉、信息结构与动效，并要求进入后逐页阅读。Lite 重做为独立搜索工作台与逐页阅读，使用自身的暖黑、琥珀金与米白配色；Pro 沿用现有专业方案。两版使用一致的数据源、研究记录、分析结果与计算，分别设计数据展示和操作路径。

发布基线为线上 `896e079`（恢复原专业入口、报告和常驻侧栏）。Pro 查询页、侧栏、专业样式和阅读状态沿用该基线；Lite 路由与版本切换保留禁止自动采集同行数据的保护。后续报告修订改善两版的内容组织，保留 Pro 专业导航和数据主线。

## 完整报告与视觉分工修订

用户指出两版生成报告都有问题，并要求重新检索同赛题项目。当前上传目录为空，既有归档路径不在本环境；本轮依据已记录仓库及固定 SHA，重新读取企er、Hermes、见微的 24 个相关源码文件。采纳企er的事实／冲突／未知区分、Hermes的事实先读与同报告两种阅读方式、见微的逐项引用与失败保留观察。未知不包装为风险，不引入演示进度、置信百分比或确定付款结论。精确取舍见 `docs/report-reading.md`。

修复的具体遗漏是 Pro 未展示已保存风险和行动，Lite 未展示详细维度、行动和改判条件。新共有读模型只读取当前拥有记录的可用保存报告；两版均提供核心判断、关键发现、待核查事项、完整分析、行动、改判条件与对应出处。短摘要仍为 100–200 字，正文不受此摘要限制。模型失败时保留保存报告及原生成时间；没有保存报告时展示已取得财务观察，并明确其来源与状态。打印包含正文及引用附录。

最新 Lite 以 Hermes 的集中输入、紧凑玻璃面板、单任务入口和分层阅读为主要结构参考，使用析光自己的暖黑、琥珀金与米白配色。主视图收拢为一个重点色，金额用明确单位的紧凑展示；舍入值标明约数，完整精确金额仍可查看并保留在出处和打印中。首页、历史样例与阅读路径各自呈现一个任务；公司结果用四个独立页面组织概览、数字、线索和下一问。指标与原文仍按自身引用精确关联，可反查引用并本地筛选／分页；完整报告与来源可展开、打印。Hermes 本轮源码与实际页面的区别见聚焦研究记录；八个软件的旧对照保留为 [背景研究](software-ui-reference-review.md)。

## 路由与阅读动线

| 入口                                    | 体验                                                         |
| --------------------------------------- | ------------------------------------------------------------ |
| `/`                                     | Lite 搜索页：公司、年度和本账号最近报告。                    |
| `/?view=example`                        | 历史样例页：真实原文与同源数字，明确样例主体和年度。         |
| `/?view=guide`                          | 阅读路径页：逐步说明如何从公司资料进入数字、证据和下一问。   |
| `/company?run=…&experience=lite`        | Lite 默认概览页，同一条保存研究。                            |
| `/company?run=…&experience=lite&page=…` | `overview`／`numbers`／`sources`／`questions` 四个独立读页。 |
| `/query`                                | Pro 企业确认与年度选择。                                     |
| `/company?run=…`                        | Pro 研究报告，以及既有的七个 F 数据目的地。                  |
| `/?view=story`                          | 保留原滚动证据介绍。                                         |

Lite 的查询沿用既有主体匹配、候选确认、年度选择、取消、所有权隔离与 `reuseExisting` 语义；它在提交后进入独立的 Lite 结果页面。Pro 保留报告、财务走势、行业对比、披露线索、扩展核查、数据覆盖和来源比对。

企业页上的 Lite／Pro 切换和 Lite 翻页保留同一条 `run`。切换只改变前端呈现，不创建研究、不刷新来源、不启动模型，也不把 Lite 当成新的服务端研究模式。已有后台研究按其真实状态继续运行。没有当前研究时，两版分别回到自己的入口。旧章节锚点继续进入相应独立页面；链接可直接打开、刷新和浏览器前后退。本页内容可自然滚动，页面切换不劫持滚轮或编辑键。打印无论从哪一页进入，都保留完整报告和出处。

## 早期光学迭代的研究记录

本轮实际重新体验四个参考站：JieJoe 的完整滚动章节、指针、扫描揭示、按住交互与全屏导航；Qier 的研究室、示例填入和帮助；HERMES 的对话／搜索／筛选模式与多层动效；铭察秋毫的条件展开、侧栏和方法目录。此次访问与截图在 `output/reference-review/v2-jiejoe/`、`v2-teams/`，旧 Lite 的本轮基线截图在 `v2-current/`。没有提交他站金融研究或聊天；未触发的查询后动画只记录为代码观察，不冒充真实体验。HERMES 明确标为演示的数据不移入本产品。

此前光学方向以 JieJoe 的炭黑、霓虹巨字、轮廓文字和整段视觉切换为主要参考，结合本产品“透视公司”的语义：原创折射棱镜作为场景主角、本地 Canvas 的三层光轨与扫描高光、随指针响应的空间透视、错向滚动文字、荧光滚动带、全屏菜单换景。查公司、看数字、追依据三个章节在悬停、聚焦和点击时切换实际预览。原生输入与年度选择保留完整交互。

证据章节增加可用键盘和触屏操作的扫描滑杆，叠合展示松原安全 2025 年报第 190／191 页的真实摘录，并注明页码及历史样例；两页均为现金流量补充资料，不能称为两份不同公司的报告或实时扫描结果。金额保持原值，原文弹层保留完整摘录与来源链接。光学图由 Image Gen 为本项目生成，来源在 `public/showcase/SOURCES.md`；不复制他站品牌、图片或源码。

装饰动效只管理呈现，不触发研究、不模拟加载或完成，也不把财务金额做成计数动画。保留原生滚动、键盘和触屏操作；减少动态偏好提供静态阅读。Pro 的专业数据页与既有图表语义继续保留。

本轮细节打磨增加了章节回看、深链接定位、失败后重新读取、未匹配主体说明，以及 AI 报告尚未完成时已取得字段来源的直接入口。首页示例填入与 URL 查询按账号和查询范围隔离；错误文字随语言切换更新。磁吸按钮在禁用或移出后可复位，容器布局变化会刷新滚动动效定位。窄屏保留顶栏控制、44px 主要点击区域和章节导航的可访问名称。实际浏览器走查还发现并修复了桌面及 320px 英文标题裁切、375px 中文查询按钮换行，并增加对应几何断言。

## 同一份事实与上下文

Lite 四个独立读页读取当前拥有者的真实研究与已保存报告：摘要展示可用判断及实际进度，数字保留选定年度、口径与精确金额，来源打开已有证据，问题接续统一助手。没有匹配主体或年度、字段缺失、来源冲突、模型未配置及任务失败均保留其实际状态，不用展示样例代替查询结果。

Lite 与 Pro 共用既有 API、缓存、整数分计算和财务规则；既有来源覆盖、刷新、重试、私有资料边界和访客／账号隔离不因体验变化而改变。历史示例始终保留其公司、年度与来源，不充当当前公司判断。

报告推荐问题沿用同一套提交语义，绑定拥有者的 `run`、年度、显示的利润口径和已保存报告 generation。普通助手建议仍只填入可编辑草稿。体验切换不能借用其他账号或更新后的报告版本重新解释旧问题。
