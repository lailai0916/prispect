# 照见 CashLens：产品、研究与实施方案

状态：方案已自行审查，进入实施。核验及决策日期：2026-10-01，北京时间。事实依据见 [research.md](research.md)、[rules.md](rules.md) 与 [source-manifest](../data/source-manifest.json)。本方案将随实际实现更新，不能把计划功能视作已交付。

## 1. 定位与决策

一句话定位：为采购与经营负责人核查一家上市合作方的“利润是否兑现为经营现金”，把一条经营说法变成可重算、可追溯、可继续询证的核查底稿。

具体任务：在长周期采购合作前，使用双方已能取得的年度合并材料，核查利润增长与经营现金之间的差距，并形成针对票据结算、应收回款、备货依据的材料请求。只支撑合作前财务线索核查，不决定投资、授信或公司可靠性，不预测违约概率。

目标用户与付费意愿属于待验证假设。专业机构原始披露证明现金配比、账龄及期后回款属于实际尽调方法；没有本队真人访谈。业务价值先通过可复现核查任务证明，不宣称节省比例、客户认可或市场验证。

三候选已比较：现金兑现核查、客户集中与应收核查、宣传说法交叉核查。选择第一项，因为已取得两份真实年报、数值可独立重算、核心信息可在 30 秒内呈现；第二项受客户匿名限制；第三项的语义裁定范围宽且容易变成通用问答。详见研究文档。

## 2. 防止同质化

已有商业产品覆盖企业评分、多源画像、舆情与投研 Agent，不能宣称本项目首先实现了这些能力。现金桥也是已有会计方法，不能把方法本身当发明。

本次的产品取舍是“核查一条说法”，而非任意公司搜索或综合评分。核心体验把三件事连接：同口径现金桥、原件定位与双向解释、证据压力测试。评委可以亲手移除附注或切换母公司口径，系统实际重新分析，停止没有材料支持的结论，并生成明确的补件问题。这是可展示的产品差异，不是对所有竞品的能力否定或首创声明。

同一组占款数字保留两种可能解释：扩张与结算结构变化，或回款/去化压力。管理层解释只标为公司说法，公开财报不能独立裁定是否坏账。报告列出目前材料能证明的事实、不能证明的因果和下一步需提供什么。解释质量优先于刺激性的风险标签。

## 4. 用户旅程和网站职责

1. 入口：首页提出可检验的问题，用已核验样本的真实数据对比进入核心案例；清楚标注公开报告与历史期间。
2. 工作台：显示真实任务、状态与材料覆盖；新建、重新打开、复制、比较已有任务。
3. 新建核查：选官方样本，或导入支持的结构化材料；确认公司、期间、单位、合并口径与核查目标。
4. 材料中心：列表、筛选、来源/日期/哈希/页码、删除未被任务使用的材料；原件读取及导入结果。
5. 任务执行：展示真实阶段事件，不用假进度动画；失败可重试，有实际错误说明。
6. 报告：结论、两年指标、净利润到 CFO 的现金桥、证据完整性、支持/不足/冲突检查、不同解释及后续问题。每个图形数据来自处理结果。
7. 证据核查：抽屉/页面展示短摘录、来源、页码、主体、单位与期间；本机原件定位和公开原件链接。
8. 压力测试：明确“改变本次提供的材料，重新核查”，不会声称原公司没有披露；保留原任务并另建任务，差异可比较。
9. 历史复用：刷新不丢任务；复制可替换材料；问题完成状态保存。
10. 输出：可实际下载的报告 HTML/JSON，适合打印的版式；必要时服务端 PDF 导出，输出必须用真实报告数据。
11. 方法与演示：公式、支持边界、规则/模型分别承担的任务、两种解释及局限；显式确认后重置演示工作区。中英文界面同等核心流程。
12. 账号：公开首页与示例，真实注册/登录后进入私人工作区；刷新恢复会话，账号设置可改姓名和密码、退出；账号 A 无法读取或操作账号 B 的材料、任务与导出。重置只影响当前账号。

页面共享服务端任务与材料，不堆积空页面。只有有效操作才展示为可用。

## 5. 数据和方法

范围：两家公开上市公司的 2025 年年度合并现金流补充表及其 2024 比较列。真实案例松原安全与海康威视；第三例人为仅提供选定材料。财报非实时状态，行业不同，不作健康排名。

原件、SHA256、发布日期、PDF/印刷页码已核验。原始 PDF 保留本机并忽略 Git；提交来源元数据、必要短摘录与事实字段，提供哈希校验下载脚本。报告原文不改授 MIT/CC 许可。商用再分发须另核权限。

输入支持 JSON/CSV 规范与文本型 PDF 提取。PDF 自动提取须校验表名、列顺序、期间、单位与合并范围；无法确认时返回预览或信息不足，不猜值。扫描件/OCR、任意企业覆盖和私有工商数据库不是承诺能力。结构化导入和界面编辑必须接受新数据而非只认样本文件名。

货币值以十进制字符串记录，按币种和单位转为整数分计算。缺失为缺失，不填零。净利润和经营现金均必须来自合并年度口径；混用母公司、不同期间、不同币种或无法确认单位时停止相关计算。

现金桥：合并净利润 + 存货调整 + 经营性应收调整 + 经营性应付调整 + 其余已披露调整分组 = CFO。完整附注存在时其余分组另对原表求和；只有头部指标时可显示差额，但不能把差额当成已经解释的来源事实。应收现金桥调整不等于单一应收账款余额变化，存货调整也不直接等于滞销。

现金转化比例 = CFO / 合并净利润，净利润 <= 0 时不产生通常比例解读；同比基数为零或负值时不显示常规增长率，改呈现金额变化。任何阈值只用于排查顺序，不代表信用等级，不产生任意总分。

重要判断区分原文事实、派生计算、管理层说法、产品规则与待验证假设。输入存在冲突时展示双方证据并拒绝静默覆盖。所有结论保存输入快照，历史任务不因后续材料删除而变。

## 6. AI 与确定性逻辑

方案启动时本项目没有可用模型 API 凭据；随后用户提供并授权使用 TokenFlux 第三方 OpenAI 兼容接口，已用公开年报数据完成真实调用。服务声明的模型 ID 为 `gpt-6.1-sol`，本项目没有独立验证其上游身份。凭据只放在受保护的服务端配置中。基础闭环不依赖联网模型：解析、单位/期间/口径验证、金额计算、证据定位和问题选择由确定性处理完成。

可选智能解释必须在每次新建任务中主动勾选；复制或压力测试新任务默认关闭。输入仅含本次被采纳的同口径结构化观测与必要摘录，撤回、冲突和未采用的材料不发送。输出需逐项来源 ID，拒绝不存在的引用和金额；这些校验不等于语义正确性证明。调用超时或失败保留规则报告并标示模型未完成。一次公开数据实测完成用时 23,238 毫秒，默认超时 60 秒、上限 90 秒，不承诺固定速度。未选择或未配置时明确显示规则核查。

本项目开发阶段由 AI 工具参与调研、产品与设计决策、代码、数据核对和展示制作；这些判断尚不能归为三位成员已独立完成的贡献。团队醒来后必须复核与理解。实际模型调用、规则模式与开发工具用途在 AI 使用说明中分别披露。

## 7. 技术与接口

选择 TypeScript strict、React/Vite 前端、Express 服务端，单机多账号。Node 22.23.1 已安装，Vite 官方要求 Node 20.19+/22.12+，满足。PDF 使用已核验 pdf-parse 2.x。主要依赖固定到实际安装版本并保留锁文件。

服务端本机绑定 127.0.0.1:4317，前端开发 127.0.0.1:4318；生产构建由服务端同源提供。账号与会话使用 SQLite，每个用户工作区独立原子保存；任务异步执行、保存阶段与输入快照，单进程串行化写入避免覆盖。当前交付支持单进程自托管多用户，不宣称多节点生产集群。上传有格式、大小、内容和路径校验，不远程抓取用户任意 URL，不执行资料中的指令。

密码使用随机盐与 scrypt，服务端只保存哈希；随机会话令牌只保存摘要，Cookie 为 HttpOnly、SameSite，并有过期与注销。写操作校验 CSRF，注册/登录限流。部署时配置实际 HTTPS APP_ORIGIN 与安全 Cookie，反向代理同源，持久卷与备份覆盖账号及工作区。无邮件服务时不显示虚假邮件找回入口。上线前仍需运营方落实域名、TLS、备份、监控、隐私与数据授权；这些条件不冒充已在公网验收。

API 由 shared/contracts.ts 定义：workspace/cases/materials/tasks；创建任务、查看状态/报告、复制与压力测试；更新问题；删除任务/材料；导出；显式重置。错误有中文/英文可呈现码，不将堆栈或密钥返回浏览器。

服务端提供可选模型环境变量，示例不含密钥。日志不保存凭据。启动/关闭/重启、健康检查与数据恢复步骤写入运行文档。用户已授权最终部署到新服务器及 `xuejun.cc`；采用非 root 应用进程、同源 HTTPS、完整状态备份，并以实际部署验收记录确认上线，不能把模板文件视为部署完成。

## 8. 品牌与交互系统

品牌：照见 / CashLens，含义是照见表面利润背后的现金证据；不用虚构客户、银行合作、奖项或使用量。标识采用原创几何取景框，素材说明记录构成。

信息风格：编辑式金融工作台。暖白背景、深墨蓝导航、青绿色计算与行动、琥珀色待核查、红色冲突；风险语义不只依赖颜色。首页留白大字提出问题；工作台以表格与证据行提高密度；核心报告采用现金瀑布图、细线、数值对齐与原文并读，避免雷达图和大批相似卡片。

字体：IBM Plex Sans 或可用本地同等字体负责拉丁，中文 PingFang/Noto Sans，财务数字等宽与 tabular-nums。正文至少 16px，正文行距 1.5，触控目标至少 44px；8px 间距系统，小圆角，阴影仅用于浮层；150–220ms 状态转换，支持 reduced-motion。首次操作突出下一步，复杂核查项渐进展开。

中文优先、完整核心英文切换；桌面 1440px、手机 390px、展屏 1920px，另查 768px。打印视图单独设计。首轮浏览器视觉检查后必须修正问题再复验。

## 9. 演示案例与异常

- 松原 2025：合并净利润增长、CFO 下降，现金转化约 7.15%。核查应收/存货占款，保留扩产与票据解释；不得断言坏账或爆雷。
- 海康 2025：合并净利润与 CFO 使用正确合并口径，现金转化约 164.18%；用作另一个历史现金结构样本，不写“安全企业”。
- 材料不足：只提供松原头部指标，明确人为限制输入，停止原因归因，请求现金补充表与期后回款。
- 口径冲突：母公司净利润配合并 CFO，真实提示冲突与修复路径。
- 任意规范输入变化：数值改变会引起实际重算，不返回固化报告。
- 无效格式、超限文件、扫描件/无文本 PDF、零/负基数、外部模型超时、刷新与重启均可审查。

## 10. 实施与验收

以目标实际启动为起点规划 6–8 小时，允许因规则/资源调整；不机械耗时。阶段顺序：核验与有限研究（已完成）→方案（本文件）→真实处理与一条运行闭环→完整页面→反例/压力测试→视觉复查→展示文件→验收与提交。尽早集成，避免外围页面先于核心处理。

职责：主线程持有方案、接口、整合、验收与展示；独立研究线程只写研究与来源；后端线程独占 server/ 与处理测试；前端线程独占 src/，不改后端。共享合同由主线程维护，接口改动先沟通，禁止同文件并行覆盖。

验收：两例正常输入、一例缺失、一例冲突；完整入口→注册/登录→新建→真实处理→报告→证据→保存/重开→导出；改密/退出/刷新会话、跨账号读取与写入拒绝、CSRF与登录限流、密码/会话存储；公式/单位/币种/期间、每项结论和引用、刷新/重启持久化、所有路由及可见操作、上传错误与模型失败、typecheck/build/test/format/模板校验、桌面/手机/展屏、浏览器错误、打印实际输出、README 从零启动。

安排独立严格评委审查：贴题、同质化、用户证据、最易追问的原文、演示失败点、超出能力的文案、团队理解能力。以实际产品证据修复，不以模型自评打分代替核验。

## 11. 失败风险与替代

| 风险                      | 可执行路径                                                                   |
| ------------------------- | ---------------------------------------------------------------------------- |
| 模型凭据未提供/调用失败   | 规则处理保持真实可用；模型状态明确，避免承诺 AI 推理                         |
| PDF 表格提取不稳          | 返回预览和单位/范围确认；规范 JSON/CSV 导入仍完整执行                        |
| 现金桥变成普通仪表盘      | 保留说法裁定、双向解释、证据压力测试及询证动作；删除无用途图形               |
| 现场网络/API/外部原件失败 | 已下载本机原件与离线案例，服务同源；实际操作录屏备用                         |
| 数据误读                  | 合并/母公司、币种/单位/年份校验与独立重算；不推断未证实因果                  |
| 私有仓库访问与表单未知    | 准备授权说明与离线源码包；团队醒来确认评委账户与表单，不自行公开/邀请/提交   |
| 浏览器工具暂不可用        | 记录真实工具限制，使用可用的受控测试环境验证本机页面；不把未验收 UI 标成通过 |

## 12. 展示叙事与交付

3 分钟展位路径：30 秒利润/现金反差 → 60 秒现金桥和原文 → 45 秒移除附注/口径冲突 → 30 秒问题单及导出 → 15 秒范围与现场提问。

5 分钟路演：问题与目标用户 → 实际操作与证据 → 为什么拒绝武断总分 → 与常见方案的工作流差异 → 技术实现/可复现测试 → 业务假设和下一步。具体结果与测试数在成品验收后填入，不预造统计。

交付网站、真实数据与来源、方案、规则/验收记录、PDF、1–3 分钟真实操作录像、讲稿、问答、工具/素材说明、阶段截图及三位成员理解指南。不能录制/生成时保留未交付状态，不用分镜/HTML冒充文件。少量醒来行动：复核三项核心判断、分配讲解角色、确认决赛与提交表单、授权评委访问。
