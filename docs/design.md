# 照见界面设计与验收依据

2026-10-02 按用户要求重做首页、账号、工作区、报告、比较、导入和方法页面。方向是 Linear 与 Apple 的简洁、统一和克制；是否达到预期由实际页面与用户反馈判断，不用品牌级别替代验收结果。

## 信息与视觉

- 使用系统字体，正文 14px、标题 25px，金额使用等宽数字；公开首页先展示年度、公司、真实金额和进入核查的操作。
- 通过语义色变量自动跟随系统深浅主题，覆盖图表、表单、抽屉、错误与焦点；打印固定白底。石墨文字、中性侧栏和单一蓝色强调。去除大写眉题、宣传口号、彩色图标容器、装饰性渐变与重复卡片层级。
- 工作区共用导航、页头、按钮、输入、状态、来源抽屉和焦点样式。原文、公式、完整检查、文件哈希和处理记录按用途展开。
- 案例名称与说明对应已保存材料，报告标题仍保留用户自定标签，核查目标保持年度合并净利润与经营现金。

## 与任务有关的交互

现金桥使用实际金额和原表调整项。悬停或键盘焦点选中一项，其他柱降低强调，选中依据显示准确金额、年度、页码和短原文；Enter、Space 或点击打开同一来源抽屉。左右方向键可在桥步骤之间移动。此交互用于检查出处，不增加企业评级。

比较页展示真实已完成任务的金额、材料覆盖，以及被撤回或恢复的具体解释。调整材料会创建新任务并重新处理，原任务保留。视觉变化对应实际证据变化，不是预先播放的动画。

可选模型正文中，完整匹配保存快照的引用 ID 转为来源按钮；未知或有歧义的引用保持原文。React 以文字渲染正文，不执行模型 HTML。中文源文在英文界面保留语言提示。引用可以定位来源，但不能证明解释语义正确。

按钮、输入、展开、状态保存和抽屉使用短反馈；尊重减少动态效果的设置，允许键盘操作。手机与平板折叠侧栏，复杂图表和表格仅在其自身区域滚动。

现金压力沙盘将保存的人工现金计划与临时压力情景并排显示。回款比例、延后30天、突发付款是明确假设；结果按分重算，显示首个缺口期末与逆向求得的最低回款比例。只连接三个期末点，不假装掌握逐日资金。缺失输入保留未知。
