# 析光界面设计与验收依据

2026-10-02 按用户要求重做首页、账号、工作区、报告、比较、导入和方法页面。方向是 Linear 与 Apple 的简洁、统一和克制；是否达到预期由实际页面与用户反馈判断，不用品牌级别替代验收结果。

最新反馈要求更多参考 [Linear 官网](https://linear.app/)，在简约克制的基础上增加饱满度。现场浏览其首页与产品章节后，采用更紧凑的纵向节奏、精确的字号层级、细边框、浅表面与轻阴影；保留原品牌、中性配色和核查输入入口。缩短原首屏的空白，使实际财务预览更早进入视野；来源区域补充已有年报标题，金额、页码与摘录随选择同步切换。产品演算界面使用轻微的表面分层，公开导航滚动时保持可见。之前被否定的宣传大标题、棱镜、深蓝侧栏与装饰渐变继续撤回。

## 信息与视觉

- 使用系统字体和等宽金额。公开首页首屏只有一个核查输入，按本地规则分流公司、外部预付款和内部接手；未提交草稿只留浏览器会话。向下先展示带原表定位的公开年报事实，再单独展示明确标注的合成现金计划，不把它接成某家公司的预测。
- 通过语义色变量自动跟随系统深浅主题，覆盖图表、表单、抽屉、错误与焦点；打印固定白底。石墨文字、中性侧栏和单一蓝色强调。去除大写眉题、宣传口号、彩色图标容器、装饰性渐变与重复卡片层级。
- 工作区共用导航、页头、按钮、输入、状态、来源抽屉和焦点样式。原文、公式、完整检查、文件哈希和处理记录按用途展开。
- 工作区的主要入口是事项、公司查询和材料；财务工具次一级，账号与方法为辅助入口。新账号没有预装材料或企业名。公开查询优先显示已核对金额、来源和具体待核问题，完整候选编辑与日志按需展开。
- 菜单、对话框、提示与导航面板采用 Base UI，认证采用 Better Auth；关闭对话框恢复调用位置的焦点。首页滚动动效采用 GSAP 的 React 清理和媒体查询机制，尊重减少动态设置；金额和现金缺口直接重算，不播放插值数值或假的研究进度。
- 案例名称与说明对应已保存材料，报告标题仍保留用户自定标签，核查目标保持年度合并净利润与经营现金。

## 与任务有关的交互

现金桥使用实际金额和原表调整项。悬停或键盘焦点选中一项，其他柱降低强调，选中依据显示准确金额、年度、页码和短原文；Enter、Space 或点击打开同一来源抽屉。左右方向键可在桥步骤之间移动。此交互用于检查出处，不增加企业评级。

比较页展示真实已完成任务的金额、材料覆盖，以及被撤回或恢复的具体解释。调整材料会创建新任务并重新处理，原任务保留。视觉变化对应实际证据变化，不是预先播放的动画。

可选模型正文中，完整匹配保存快照的引用 ID 转为来源按钮；未知或有歧义的引用保持原文。React 以文字渲染正文，不执行模型 HTML。中文源文在英文界面保留语言提示。引用可以定位来源，但不能证明解释语义正确。

按钮、输入、展开、状态保存和抽屉使用短反馈；尊重减少动态效果的设置，允许键盘操作。手机与平板折叠侧栏，复杂图表和表格仅在其自身区域滚动。首页现金演示可用数值输入精确改日期，鼠标、触摸与键盘均能选中事件；撤回起点现金立即变成未知，不变成零。真实年报区域切换指标或公司时，同一面板同步显示当前原始金额、单位和页码。

现金压力沙盘将保存的人工现金计划与临时压力情景并排显示。回款比例、延后30天、突发付款是明确假设；结果按分重算，显示首个缺口期末与逆向求得的最低回款比例。只连接三个期末点，不假装掌握逐日资金。缺失输入保留未知。
