# 十家真实公司实测后的核心算法优化

本次修改依据2026-10-02对十家A股公司2025年报的完整线上查询与核查结果。原件、会话和截图只保存在被Git忽略的本机目录，不将原始年报或账号凭据提交仓库。本文先记录本地原件回归；线上复测结果须单独记录，不能以此代替部署验收。

## 修复与依据

| 实测问题                                                   | 修改后的处理                                                                                               |
| ---------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| 贵州茅台基本信息表的可选末列为空，主体核对失败             | 只允许明确的末尾「变更前股票简称」留空，证券代码、交易所和股票类别继续严格核对                             |
| 比亚迪同一行列出A/H股简称，误将A股代码当作H股              | 区分股票简称中的H股标记与代码的明确类别；保持独立H/B股反例拒绝                                             |
| 中国建筑封面文字顺序为「年度报告」「2025」，表头含「附注」 | 同一封面页识别相邻年度与标题；支持明确的两年表头、重述标记和括号负数，不跨页猜年度                         |
| 紫金矿业官方原件79,925,886字节，超过25 MiB                 | 官方年报下载、隔离解析、原件保留统一使用100 MiB有限预算；用户上传仍限25 MiB，账号总额仍限250 MiB           |
| 隆基绿能一行2025年有数、2024年空白，整组调整丢失           | 读取PDF矢量表格的三列单元格，按年保留已披露调整；空白年度保持未知，不填零或以残差补数                      |
| 近期公告单次读取曾耗时201.5秒                              | 时限覆盖响应正文；每篇公告只尝试一次，下载限15秒、25 MiB，整组读取限45秒，覆盖不足明确提示                 |
| 模型返回拼接枚举导致解释格式失败，以及重复假设             | 使用实际可解析的JSON示例，允许同一时限内一次格式纠正；维持12次累计请求和引用白名单，合并同一假设的真实引用 |

单位采用原表明确声明：支持财务附注页的人民币单位，以及「本财务报表……除特别说明……均以人民币千元为单位」的报告级声明并保留声明页。普通业务表的单位不能传入财务补充表。母公司或公司独立财务报表注释排除，不与合并财务数据混用。
