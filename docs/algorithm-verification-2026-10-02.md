# 十家真实公司实测后的核心算法优化

本次修改依据2026-10-02对十家A股公司2025年报的完整线上查询与核查结果。原件、会话和截图只保存在被Git忽略的本机目录，不将原始年报或账号凭据提交仓库。下面分别记录本地原件回归和已部署版本的线上复测，二者不能相互代替。

本机原件回归位于 `work/verification/algorithm-2026-10-02/extraction-latest.json`；优化前线上记录位于 `work/verification/real-companies-2026-10-02/`。新增回归覆盖上述真实版式、错误主体/年度/单位反例、空白列未知、官方与上传额度、总存储额度、响应正文取消、模型纠正及公告额度。完整 `npm run check` 已通过190项测试、严格类型、构建和格式检查；精确发布和线上结果见下节。

## 已部署版本的线上复测

核心修复提交为 `d273f9edbee3d2f317bd82e610ddaba637f8d530`，[CI](https://github.com/lailai0916/prispect/actions/runs/36999604635)和[自动部署](https://github.com/lailai0916/prispect/actions/runs/36999757574)均成功。部署日志确认服务器HTML及资产与该提交构建一致；公网另核对HTTPS健康与已发布HTML引用的42项资产。跨环境构建的部分JS哈希不一致，未用本机Node 24构建哈希代替CI Node 22发布产物的权威。

使用原专用生产测试账号重跑十家公司，遵守已有每小时限频；查询启用已配置模型，核对原件后按现有产品流程采用并生成确定性报告。九家非金融公司均取得2025年6/6项指标并通过报告核查，八家现金桥闭合；招商银行仍明确停止，未生成候选或调用模型。九份重新下载的PDF均与本地原件逐字节哈希匹配，其中紫金矿业也核对了首次测试后另行取得的同一官方原件。

独立Poppler原表核对326项金额及组件；整数分换算、比例、现金桥、报告保存与导出等126项检查全部通过。浏览器的来源页码、保留原件哈希、HTML/JSON/Markdown预览保存共45项检查通过；银行停止原因、无采用入口、无模型调用和两种屏幕宽度另通过5项检查。报告在1440px和390px均无整页横向溢出，页面错误为0。43次模型请求没有记录到JSON或字段格式校验失败；这不证明模型解释的语义一定正确。

中国建筑首轮官方年报下载两次30秒预算耗尽，共约64.5秒，未生成替代金额。其余样本完成后，通过已有断点恢复接口重读同一官方年报，恢复执行约63.4秒，累计来源请求12次；成功生成、保存并导出报告。首次失败保存在记录中，等待其余样本的时间未算入恢复执行耗时。茅台本轮约63秒、上轮约187秒；松原本轮约103秒、上轮约51秒。来源和模型延迟有波动，不能从单轮数据宣称每家公司查询都变快。

宁德时代2,000元差额、隆基绿能2024年空白和亏损年度现金利润比不适用均与本地回归一致。原始线上记录为 `work/verification/algorithm-production-2026-10-02/`，汇总为 `work/verification/algorithm-2026-10-02/production-summary.json`；本地缓存原件的API回放另有126项报告检查和45项浏览器检查，模型与实时来源禁用，未当作线上证明。以上只适用于本批样本。
