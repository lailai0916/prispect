# 原件核查刷新状态验收

本轮从本地 `21e17ce` 开始，针对用户截图中的刷新过渡状态修复。未修改金融计算、原件确认规则或后台权限；未推送或部署。浏览器使用本机 React/Express、临时演练账号与合成候选字段，不读取生产私人资料，也不将演练字段作为真实发行人的原件证据。

## 原因与改动

企业页面已通过所属账号接口读取所选记录，嵌入的原件核查又独立读取相同记录和完整历史。其 `run=null` 的初始分支同时显示新建查询表单、原件记录加载提示和历史加载提示，随后整段替换成原件内容。

- 企业页面把已读取的当前记录交给原件核查；初始化同时保留原件候选字段，仅接受 ID 与当前路由匹配的初始记录。
- 原件核查不重复读取这份初始记录，也不把未变的初始记录广播成更新。正在执行的原件任务仍保留真实轮询、取消和恢复行为。
- 嵌入视图不加载完整历史；研究库和共享账号记录订阅继续承担历史入口。独立的旧查询入口仍保留历史功能。
- 已有记录的读取和失败状态不显示新建查询表单。模块尚未就绪时使用中性原件占位和一处可访问的加载提示，减少动态效果设置关闭占位动画。
- 初始记录只用于初始化，父页面后续读取不会覆盖用户已编辑的候选金额或清除人工确认。实际原件版本变化仍由原有候选版本逻辑处理。

本机产物位于 `output/original-loading/`，不提交临时账号会话或生产数据。
