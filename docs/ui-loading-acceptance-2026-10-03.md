# 加载、切页与刷新体验验收

以 `7abb679` 为本轮起点，保留此前页面修复及研究流程提交。本轮仅本地修改与提交，没有推送、部署或修改生产资料。

## 改动

- 页面模块在本地链接悬停或键盘聚焦时预载，与实际打开共用请求和已有资源恢复逻辑。预载不挂载页面，不查询该页业务数据。
- React 过渡保留当前已显示内容；目标模块准备好后切页，再滚到顶部。快速改变目的地时，晚到模块不覆盖最终选择。
- 整页入场从 220ms 的透明／位移动画改成 120ms 的轻微透明度变化，不移动内容，也不改变固定抽屉的定位参照。减少动态效果设置下关闭动画。
- 根滚动条保留槽位，研究库的统计、筛选区和记录加载占位保留结构。新建研究页不再因记录为空而另加顶部留白。
- 研究记录使用当前语言解释错误；语言切换不重置列表或取消已有读取。刷新错误时最近研究和研究库仍可打开已读记录。
- 工作区刷新在服务确认同账号后保留已读内容，显示失败及只读重试，并暂停失败轮询。会话不可确认、失效或账号改变时仍隐藏旧工作区。
- 报告等待阶段保留评级列和来源操作的空间，尚无判断时不伪造评级或数值。已有报告刷新时继续显示原判断、金额及上次分析标识。

## 相同条件前后测量

真实 React／Express 页面，独立本机演练账号；延迟记录响应与页面模块。所有公司数据来自明确标记的合成演练提供商，没有生产登录、外部检索或模型调用。

| 场景                               | 修改前                 | 修改后                        |
| ---------------------------------- | ---------------------- | ----------------------------- |
| 空账号读取完成，新建研究输入区位置 | 下移 40px              | 0px                           |
| 研究记录读取完成，研究库筛选栏位置 | 下移 57.59px           | 0px                           |

| 刷新记录失败                       | 统计区消失             | 保留统计与可打开的记录        |
| 长文档滚到 350px，目标模块延迟时   | 当前内容隐藏，滚到 0px | 当前内容和 350px 阅读位置保留 |

这两个 0px 测量只指表中控件位置；新内容长度、实际记录数和新判断变化仍可能改变文档总高度，不声称全站累计布局偏移为零。

## 额外验证

- 键盘预载只有一个模块请求，不发业务 API；连续选择页面后，晚到资源不会切回旧目的地。
- 模块加载失败经过有限尝试后显示原失败入口；手动重试能够恢复，健康模块不重载。
- 来源抽屉打开、关闭后背景位置不变，关闭返回原按钮及滚动位置。
- 同账号工作区刷新失败后继续编辑草稿，读取重试不会重新挂载表单或清掉新草稿。
- 刷新期间服务账号改变：旧表单隐藏，重新连接后只显示新账号，旧草稿为空。
- 1440px、390px、320px 报告的深浅主题：评级列、来源占位高度与实际操作保持一致；等待和刷新后没有整页横向溢出。
- 320px 深色、减少动态效果下，占位静止且布局可用；研究库另在 390px／320px 深浅主题核对。
- `npm run check`：733 项测试通过，类型、研究资料、构建及全仓格式通过。新增三个预载测试覆盖请求共享、资源重试和执行错误停止；最后的展示微调另复查类型、构建、格式及实际浏览器状态。

本机证据：`output/loading-comfort/before.json`、`after.json`、`advanced.json`、`report-states.json` 和对应截图。会话只保存在临时目录，不随证据或代码提交。浏览器脚本使用本机合成资料与故障注入；不能作为真实查询速度、真人舒适度或生产发布结果的证明。
