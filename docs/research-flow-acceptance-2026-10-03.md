本轮使用原 React 页面、Express 接口、账号、CSRF、工作区持久化和任务状态；企业及年度公开数据由明确标记的合成提供商注入，外部检索和模型没有真实调用。

更新失败、等待取消和重试使用可控本机提供商故障：旧报告保留，取消后没有被晚到响应覆盖，重试恢复；分析失败保留旧报告，再次研究成功。不能把这些故障注入当作生产经历。

另以独立浏览器对 `data/cases/songyuan-2025.json` 做了原件路线验收：预览／确认导入和创建报告通过真实本机 API 辅助，报告与实验室通过真实 UI 操作。存货调整撤回后现金桥暂停，现金利润比保持可用；恢复后节点状态全部还原，保存报告 JSON 未改变，390px 无整页溢出且无页面异常。原始 PDF 本轮未下载或核验。

本机证据保存在 `output/flow-check/`：`browser.mjs`、流程截图、年度错位前后记录及 `research-quality/`。产物目录不提交账号存储、Cookie 或浏览器配置。

## 两条可复现演示路线

这两条路线分别展示“原件如何支撑计算”和“研究报告如何进入深入核验”。先在本机演练账号中准备材料，使用真实应用的账号、保存、路由、图表、抽屉和计算；不向生产账号注入演示资料，不新增 `?example=1` 或公开实例页面。

### 启动本机演练

在仓库根目录运行：

```sh
npm run build
node --import tsx scripts/serve-research-demo.ts
```

脚本从自身路径定位当前仓库，不依赖 `/workspace/prispect-improve`。默认绑定 `127.0.0.1:4336` 并创建独立临时目录；终端打印网址与目录。打开网址，在本机创建一个演练账号，不使用真实账号密码。可用 `PRISPECT_DEMO_PORT` 调整端口；`PRISPECT_DEMO_DATA_DIR` 只接受空目录。服务拒绝 production 模式和已有资料目录，不自动删除演练材料。停止用 Ctrl+C；再次运行默认生成另一个独立目录。

这台服务使用明确标注的合成企业 `601234`、2024/2025 两年合成财务值、规则报告与本地依赖试验。模型密钥不会启用，新闻、帖子、年报抓取不会执行；同行未配置时保持缺失。后台对外 fetch 被禁止，邮件通道关闭。财务来源链接仅表示字段格式参照，哈希是合成输入摘要。它验证交互与计算，不证明联网 Grok 的研究质量。

### 路线 A：松原安全原件 → 现金桥 → 撤回与恢复（约 2 分钟）

准备 `data/cases/songyuan-2025.json`。这是仓库已保存的真实 2025 年报摘录与调整行，公开原文链接、来源 SHA256、页码由 `data/source-manifest.json` 记录；本轮不会把它说成刚刚联网取回的资料。JSON 文件保留可核对的输入，但不等于原始 PDF 已附入演练账号。

1. 登录本机演练账号，从侧边栏“核查工具”打开“材料”，点击“导入材料”，选择上述 JSON。预览公司完整名称、2025 年度、人民币元、合并范围和 190–191 页摘录，主动确认导入。
2. 从“核查工具”→“财报核查”创建新核查，选择已导入材料并确认 2025 年，点击“开始核查”。保存后进入 `/tasks/:id`；无模型配置时规则报告仍保存，不伪称 AI 研究完成。
3. 展示合并净利润 **366,373,098.93 元**、经营现金 **26,197,123.70 元**及 **7.15%** 现金利润比。打开“分析依据与核查记录”→“图表与来源”，选择现金桥“存货”柱，定位 **−321,030,062.96 元**、191 页原话；经营性应收调整为 **−514,221,076.54 元**。它们是现金流补充表带符号调整，不能替换成年末余额变化。
4. 切到“证据实验室”，选择“存货调整”的事实节点。先指出它通往哪些计算和待检验解释，再点击“在试验中撤回”。应看到完整现金桥及依赖存货的路径暂停，**现金利润比仍可独立计算**，回款相关独立路径保留。选择“在试验中恢复”或“恢复全部”，金额与路径回来；已保存报告和评级不被这次本地试验改写。
5. 选择扩张备货／去化压力解释，展示仍需存货结构、库龄、订单执行与期后去化等材料。这里的“开始公司研究”是通往另一项公开研究的入口，**不是原件页已经完成了定向搜索**。本机合成 provider 不会为真实松原安全伪造公开研究。

现场讲述：先让评委看见“撤回一条依据，只暂停真正依赖它的判断”。不要把现金利润比解释成销售回款率、企业安全概率或因果结论。需要检查 PDF 时使用事先合法取得、SHA256 匹配的原件，或现场主动打开公布的原文链接；没有文件就保留明确缺口。

可选 30 秒反例：同样导入 `data/cases/hikvision-2025.json`，使用 2025 年合并净利润 **15,433,655,239.83 元**与经营现金 **25,339,411,083.10 元**。现金高于利润不会自动成为“企业安全”的结论；其经营性应收调整是正 **8,011,882,904.98 元**。PDF 页码 229 与印刷页码 228 已在 manifest 区分。不要给它编造一个未计算的公司研究等级。

### 路线 B：研究报告 → 挑战解释 → 图表 → 助手 → 依据（约 2 分钟）

本机稳定案例是 **“合成研究样本（非真实企业）” `601234`**：2024 营收 800,000、净利 80,000、经营现金 70,000、存货 80,000；2025 营收 1,000,000、净利 100,000、经营现金 60,000、存货 120,000，均为元。

1. 在“新建研究”输入 `601234`，选择明确标注的合成候选。创建 2025 年研究，自动进入研究报告。摘要及财务规则等级 **C** 来自保存的合成金额；现金利润比为 **60%**。查看研究过程，模型调用与公开工具调用为 **0**，不能讲成 Grok 刚刚搜遍了全网。
2. 点击摘要的“挑战解释”，选择“扩张备货”，点击“挑战这个解释”。此服务只调用实际规则引擎：营收和存货同时增长形成一条支持线索，存货／营收从 **10% → 12%** 形成一条反向线索；因此可呈现双方线索。结果明确“未进行定向搜索”，库龄、订单和期后交付继续标为未取得。支持与反向线索不改写报告等级，也不裁定差异原因。
3. 进入“财务分析”，先看“利润与经营现金”四卡，选择 2024 再回到 2025，核对主要金额、趋势和数据年度联动；点击卡片的“字段与来源”打开已有来源抽屉。此案例没有真实同行，比较区域应保持缺失，不能临时填一个漂亮的均值。Esc 关闭后回到刚才按钮与滚动位置。
4. 点击右下角“析光助手”，直接问“利润增长但经营现金下降，先核对什么？”不选择企业，助手使用当前账号、当前企业与当前年度的公开演练上下文。提示问题先填入可编辑草稿；发送后输入框清空。无模型配置时显示已有金额与询证问题，不宣称智能分析完成。本机合成字段只有格式参照首页，没有实际财务取数链接，因此这类回答的财务引用为空；不把参照首页伪装成引用证据。
5. 问“网站的隐私政策怎么处理材料？”验证助手在同一会话内转到真实文档依据。再进入公司“原件核查”，应看见未取得原件状态；返回路线 A 的自己上传原件报告，核对真实摘录。这两个来源分支必须保持可辨认，不把合成公开快照冒充已采用的原件。

实时展示可将路线 B 换成自己账号里已正常取得的真实 `300893` 松原安全或另一支持公司，固定所选年度后再开始。只有真实定向搜索完成、有实际工具步骤与来源记录时，才能介绍 Agent 补查；保存版必须保留原取得日期。官方解析、模型配置或请求失败时，继续展示已保存资料／重试／取消，不切换合成案例却仍沿用真实公司名。
