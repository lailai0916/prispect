# Model-provider use review

Reviewed on 2026-10-02. The current model integration uses the operator-supplied TokenFlux `.dev` endpoint. Credentials remain on the server and must not be included in this document.

TokenFlux's [usage policy](https://docs.tokenflux.dev/docs/tos/usage-policy.html) requires explicit written authorization to repackage its capabilities as a SaaS or other service offered to third parties. An API key or account balance does not establish that authorization. The operator has been asked whether the Prispect website has the required permission; no affirmative evidence has been received in this review. Do not describe the provider as a licensed or verified partnership. This review has not changed the existing model configuration.

The provider also describes specially marked data-sharing groups. Neither the selected account group nor downstream processing terms have been independently verified. Do not claim zero retention, no training, a particular processing country, or a signed data-processing agreement without evidence. The public privacy policy documents actual payload boundaries and the user's separate choices for public research and private financial reviews.

Before expanding the public AI service, obtain the relevant authorization and account/data-processing terms or use a provider that permits the intended service. Deterministic financial and payment calculations do not depend on the model provider. Provider access or retention claims must be updated from current evidence, not copied from another domain with a similar name.
