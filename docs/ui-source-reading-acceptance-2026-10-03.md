# 来源阅读状态验收

本轮以本地 `224c0d6` 为起点，继续检查更新、分页和抽屉交互。仅本地修改与提交，不推送、不部署，也不修改生产资料。

## 实测问题

“新闻与公开讨论”原先把快照日期、内容和采集记录放进组件重建条件。同一研究收到新的公开资料后，整个阅读区都会重建：展开列表收起，筛选清空，来源抽屉关闭。条目标识又包含列表序号，插入新来源会改变后续条目的标识。点击当前页签也会重复执行切换逻辑，把选择重置为第一条。

## 修改后的行为

- 仅账号、研究记录或主体范围变化时重新初始化阅读区。同一研究的资料更新保留展开状态、筛选、所选来源和滚动位置。
- 新闻条目优先使用已取得的来源链接，公开讨论使用保存的稳定编号。新条目插入、排序变化，以及旧新闻记录补上目录编号，不重新挂载同一来源的阅读正文。
- 新条目把所选来源推到下一页时，列表页码跟随这条来源；用户明确翻页或改变筛选仍使用其新选择，并从结果列表顶部开始。
- 点击当前页签保留操作状态；键盘方向键、Home 和 End 仍能切换类型。
- 当前媒体从新快照中消失时，保留可见的筛选条件并标注“本轮无条目”，不把这项选项计入已取得媒体数。即使新快照为空，筛选仍可清除。
- 打开的来源抽屉使用当前快照中同一条目的节选，更新不关闭抽屉；条目不再出现在新快照时关闭抽屉，并把焦点交回来源列表。

这些行为只浏览已取得的公开资料，不发起采集或模型分析，不改变财务计算、评分或采用材料。当前范围不匹配的企业资料仍不显示。
