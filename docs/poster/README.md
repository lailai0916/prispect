# 析光 Prispect 展示海报（80 × 200 cm）

[prispect-poster-80x200.svg](prispect-poster-80x200.svg) 是学军中学「回响·48H 青年创造营」X-Ray 方向的竖版展示海报，可直接交付印刷。

## 规格

- 成品尺寸 800 × 2000 mm，`viewBox` 中 1 单位 = 1 mm；背景铺满到边缘，无额外出血。印刷方要求出血时，把深色与浅色背景各向外延伸 3–5 mm 即可。
- 所有文字已转为路径，不含 `<text>`、字体文件、位图、滤镜、样式表或外部链接。字形来自 Noto Sans CJK SC 与 Inter（均为 SIL OFL 1.1）。`aria-label` 与 `<desc>` 保留原文，便于检索。
- 安全区：左右 55 mm，顶部 50 mm 以内只有背景；底部 110 mm 留给易拉宝底座卷入，只放装饰色带。
- 颜色为 RGB，取自产品的紫色强调色与深浅画布。大面积深色是深靛蓝而非四色黑，转 CMYK 时请按印刷方的 ICC 设置打样。
- 字号：口号 102 mm，正文 19–25.5 mm，来源说明最小 14.5 mm。

## 内容依据

- Logo 使用 `src/components.tsx` 的几何标志原样等比放大；口号使用产品规定的中英文原文。
- 案例取自 `data/cases/songyuan-2025.json`：松原安全 2025 年报合并现金流量表补充资料（PDF 第 190–191 页）。合并净利润 3.66 亿元，存货 −3.21，经营性应收 −5.14，经营性应付 +2.78，其余已列示调整的计算合计 +2.17，经营现金净额 0.26 亿元；四舍五入后的数值同样逐项加总一致，现金利润比 7.15%。海报注明这一差距只提示继续核查，不代表坏账、违约或投资建议。
- 范围说明与当前产品一致：公司研究只支持 A 股，财务口径为人民币年度合并报表。
