## 设计落实

这次从搜索与阅读任务重新组织 Lite，未继续扩展 Pro。页面采用深蓝搜索主场、蓝色滚动带、浅蓝原件区、紫色阅读流程与荧光绿结束区。装饰为本地程序几何，不再用一张棱镜重复铺各页。

1. 首页以真实公司搜索为中心，四类阅读问题分别指向财务、公开记录、风险待核查、口碑线索。点击公开记录或口碑入口直接选择对应舞台；主体与年度仍由真实 composer 确认。
2. 同一真实历史样例的三幕财务展示：金额同轴对照、精确差额、原文出处。幕次是展示选择，不是研究完成进度；金额保持原值，差额不作为现金桥或成因证明。其他通道用文件层叠和问题气泡解释阅读路径，未取得材料明确说明。
3. 结果的线索调查是独立阅读体验：默认三张可区分的问题卡，附该项已保存判断；判断→typed 指标→对应来源→下一问。原文含实际期间、页码、节选及链接，也可反查引用它的判断。来源只做本地类型筛选和每页六项分页；完整来源及正文保留展开与打印。
4. 金额片使用指标 ID，保留精确 CNY、该项来源、主体、年度、分析口径与保存代次。相似数值不用于猜引用。用户切换数字的显示利润口径后，追问按当前口径提交，保存报告自身的合并分析口径仍明确。
5. 两行文字不同逐字入场、问题卡装配、同刻度数据整串揭示、文件层叠、原文切幕、滑杆透视、来源定位和指针几何共同构成动效。呈现不改金额、执行状态或评级；保留键盘、触屏、原生滚动和减少动态。

## 素材与验收边界

只独立实现交互和视觉思路，不搬第三方品牌、角色、字体、图像或无整体许可的源码。公开源码与许可证不同；Ask the Company 的 MIT 已核实，其余不因公开就推定可整套复制。冻结旧竞品 evidence 保持原字节。

此次新运行、源文件版本与收据在 ignored `output/reference-review/v4-teams/`；前一轮蓝色 Hermes 深度搜索在 `v3-search/`。本地演示、合成档案、源码观察及上线网站分别标记；不把模拟回答冒充真实模型成功。游戏资料只保留为历史取证，不参与此次 UI 选择或新功能。
