# 图表与章节定位的交互验收

本轮以本地 `efbb9cb` 为起点，继续修复实际操作中的布局变化。保留此前的字体、四组图表、导航、加载占位与刷新保护，只修改本机文件，没有推送或部署。

## 已复现的问题与处理

- 带 `focus` 参数打开报告后，每次来源快照更新都会重新滚回指定章节。现按本次定位请求记录已完成的展开，只在首次取得目标内容或用户明确改变定位时跳转。正常访问仍从顶部开始，显式 hash 跳转仍能展开内容。
- 两处同行读取把语言作为请求清理条件，切换语言会中止读取、清空等待状态，失败反馈也随之消失。现只在企业、年度、账号范围变化或组件卸载时取消；响应使用到达时显示的语言解释错误。
- 同行参照按钮等待时增加图标和长文案，造成按钮增宽、标题换行。现使用等大的动作／加载图标，保留动作文字，通过禁用状态、转动图标和无障碍标签表达实际等待。
- 图表先按最小宽度建立 SVG，再异步测量容器；隐藏页签和屏幕方向切换时，SVG 会按过期比例瞬间变高。现绘制前测量宽度，隐藏图保留上次有效宽度，各类绘图区固定屏幕高度；打印单独恢复按页宽等比缩放。
- 后退到带章节定位的公司页或文档时，页面再次对齐章节，覆盖了浏览器的阅读位置恢复。现每次访问分别记录位置，等实际内容足够长时恢复；章节只展开，明确的新定位仍跳转。恢复完成后停止监听，用户滚轮、触摸或滚动键操作会提前停止恢复。

## 相同条件前后对照

真实 React／Express 路由、独立本机演练账号、同样的合成财务字段与受控 HTTP 响应。没有生产登录、外部检索或模型调用。

| -------------------------------------- | ------------------------------------ | -------------------------------------------- |
| 行业定位后，滚到 260px 再更新来源快照  | 自动滚到 888px                       | 保持 260px                                   |
| 同行按钮从正常进入等待                 | 宽度 88px → 144px                    | 108px → 108px，位置不变                      |

固定绘图区只针对图形本身。新资料、解释、真实错误提示及不同语言内容仍按实际长度排版；这些测量不代表全站布局偏移为零，也不证明真人舒适度或真实查询速度。

追加的返回问题在图表修复后的中间版本复现：公司页读到 260px，离开后后退落在 764px；修复后，包括故意延迟记录响应在内，均回到 260px。文档读到 900px，后退曾再次跳到隐私章节的 2519px；现保持 900px。

同一财务地址的两次访问分别读到 340px 和 520px，后退／前进分别恢复各自位置；新访问从顶部开始。原生文档锚点保留 800px／1000px，企业锚点保留 300px／440px 的各自阅读位置。页面刷新也保持已记录的位置。

## 边界与验证

59 项命名浏览器检查通过：

- 请求定位的章节尚未取得时等待；资料到达后展开一次，后续更新保持阅读位置。明确改定位、hash 跳转和普通页面访问仍正确。
- 两个同行入口切换语言时保留请求与真实等待；失败时按当前语言解释，旧同行资料仍可阅读，重试成功后错误消失。
- 切换年度仍取消前一年度请求；其晚到响应不改变已选年度、不覆盖已保存的对应年度资料，也不生成错误。
- 依据抽屉 Esc 关闭后焦点返回原按钮。
- 390px、320px、844px 横屏、1440px 的深浅主题；深色采用减少动态效果设置。页面无横向溢出，图内文本仍使用至少 12px 的字号。
- 所有实际观测到的柱图、折线、哑铃图高度保持 210px；横向比较 116px，同行分布 250px。
- 打印显示四组共 16 张主要历史卡片，并按原比例适配页宽；保留存货和应收的补充内容。页面没有运行时异常。
- 历史恢复覆盖延迟响应、主动滚动打断、返回过程中改去另一页、重复地址、原生锚点和页面刷新。旧响应及旧恢复监听不影响新的目标页。

`src/page-scroll.ts` 仅保存随机访问编号与滚动坐标，不保存报告、草稿或账户内容。滚动帧只更新最多 100 项的内存记录；离开页面时写入对应历史条目，保留其他历史元数据，不高频调用 History API。目标变短或迟迟未取得时，四秒后停止等待；这一边界不保证任意长延迟下都能恢复原位置。

新增九项回归覆盖历史状态校验、独立访问位置、连续切页时的未提交目标、坐标缓存范围、等待实际内容、恢复只执行一次、用户滚动优先、废弃导航与超时清理。

本机证据为 `output/navigation-comfort/` 中的 `before.json`、`after.json`、`advanced.json`、`history.json`、脚本与截图。Cookie 和账号会话只留在临时目录，不随证据或代码提交。这些脚本的 HTTP 延迟、同行数值及故障为明确合成条件，不是服务或模型实测。

`npm run check` 全部通过：742 项测试、类型、研究资料、构建及全仓格式检查。固定版本的仓库规范检查通过；未查询远端元数据、等待 CI 或部署。
