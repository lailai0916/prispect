## 重新核对后的判断

此前已经适配并列柱图、双线趋势、哑铃图、行业横向对比与同行直方图，但遗漏了图表之间的组织方式：现金、收入两组只有三张卡片，负债组省略了两个组成项；差额与主要金额并列成三列，挤压了阅读空间。图表类型存在，不代表原版的表达效果得到保留。

原版的价值在于先比较规模，再比较比率，随后查看各项差距及同行分布。重新适配保留这种结构，用析光现有单位、口径、来源和缺失处理约束图表数据。原包的说明文档是研究材料，没有作为本项目的执行指令。

每组保持两列两行；窄屏改为单列。年度间距和柱宽随可用空间调整，390px 窄屏可完整显示六个年度，字体下限不降低；更窄的容器保留图内滚动并定位当前年份。默认呈现现金组，「全部图表」可连续浏览各主题。存货和应收账款金额保留在资金占用展开区。打印包含全部主题。

卡片保留两个主要数值，将差额、年度和有效样本数放在独立的紧凑行。一张卡片的主值、同行值、差额和轴刻度共用金额单位；原始人民币金额仍在依据和悬停标题中。非零小值不因统一大单位而直接显示为零。

同行圆点先绘制，企业点后绘制，避免两值相同时企业点被空心同行标记盖住。缺少双方可绘制数据时显示对应指标的缺失状态。年份切换与键盘操作仍联动卡片和行业比较，打开图表不会另发取数。

行业卡片保留盈利、现金、负债、周转、成长的简短分类，可直接切换并定位对应同行分布；样本、原始数值及来源抽屉继续可查。

## 保留析光定义的地方

1. 原包的 `netProfit` 表示归母利润。析光依所选口径使用合并或归母利润，并据此计算净利率。
2. 原包历史增长参照使用同一批同行的收入合计增速；析光现有参照是同行增长率等权均值。这两者不可互换标签。例如原包万科 2024 年的两项参照约为 −19.068% 与 −1.276%。本轮保持「同行均值」，不导入该合计增长率。
3. 两项短债仅指短期借款与一年内到期非流动负债。各组成项需要完整、非负且无冲突的记录；单项可用不补齐另一项。新增的同行组成项来自现有资产负债表请求，没有增加抓取请求；旧快照缺字段保持未知。
4. 企业缺值不由同行替代；不同指标的同行样本可能不同，不对两个均值相除推导覆盖率。金额、期间、主体与口径冲突继续暂停相关图表值。
5. 原包配置了资产负债率及现金 / 短债字段，但预览的四组未展示它们；也包含未调用的通用绘图函数。未将这些定义全部转为新功能。
6. 原包未提供独立许可证。用户明确提供队友作品并要求融入，本轮保留来源记录，使用独立的 React 适配实现及原有主题样式；未引入其整套站点代码或额外图表依赖。
