# 报告阅读修订

## 问题与实现

Pro 的 AI 阅读路径只调用核心摘要与评分组件，已保存的风险及核查行动没有呈现；Lite 的四章也遗漏详细维度、行动及改判条件。修订以 `shared/company-report-document.ts` 作为只读大纲，在保存的同一资料快照／生成时间中组织完整内容，避免另开生成协议。Pro 使用连续专业文档及引用附录，Lite 使用可快速阅读的重点与可展开详读。

摘要 → 关键发现 → 独立的未知／冲突 → 维度分析 → 下一步核查 → 改判条件 → 精确指标及引用。每个判断只引用本项使用的合法指标／出处；旧报告保留旧快照、旧日期，不借新资料补齐旧判断。无模型配置时实际已取得的数据可读，规则观察不标成保存的 AI 报告。未匹配年度／主体和不支持市场的解释继续暂缓。

100–200 字要求是核心段落约束，正文的优势、风险、行动和条件完整保留。两版保存等级与另行标注的暂定等级一致，不修改存储。报告追问绑定拥有者、研究、年度、显示口径及保存生成时间；读取、展开和版本切换不触发采集或模型。
