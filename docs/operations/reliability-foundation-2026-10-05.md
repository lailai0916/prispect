# 账号恢复、资料变更记录与隔离恢复 · 2026-10-05

本轮保留现有主工作区、F 财务页面和析光助手。未访问或修改生产数据，未恢复历史九项缺失资料；邮件与恢复验收使用新建临时账号和合成原件。

## 邮件密码找回

登录页“忘记密码”在邮件服务可用时接入请求表单，邮件链接打开新密码与确认密码表单。`GET /api/auth/session` 的可选字段 `passwordRecoveryEnabled` 保持旧客户端兼容。

`POST /api/auth/password-reset` 验证邮箱、固定站内返回路径，按 IP 和邮箱哈希限流；已注册与未注册邮箱得到相同确认。`POST /api/auth/password-reset/confirm` 调用现有 Better Auth 原子消费令牌：一小时过期、只能使用一次，弱密码在消费前拒绝。重置注销旧会话，保留账号 UUID、两步验证、通行密钥和工作区；不能找回丢失的验证器或恢复码。

邮件链接使用 URL fragment；`appearance-init.js` 在应用和访客统计启动前将令牌移出地址，短暂保存在页面内存。也清理旧的 `?token=` 链接。不存入浏览器持久存储，不提交给访客统计；刷新后可能需要重新打开邮件链接。

未配置 SMTP 时明确不可用，实际投递失败也返回失败。本轮使用内存邮件接收器，**未验证生产 SMTP 或实际收件**。

## 资料变更记录

每个账号工作区的 `.audit/events.jsonl` 使用私有目录 0700、文件 0600。记录操作 UUID、服务端时间、动作、原因、阶段和标识 SHA256；过期事件记录创建/资格时间，失败 Agent 缓存还记录资格状态。

覆盖上传过期、孤立 blob 过期、主动放弃上传、材料删除、研究删除、缓存移除和工作区重置。不含原文、文件名、路径、邮箱、聊天、金融金额或凭据，不发送给模型。账号由独立目录关联，**不能据此识别具体设备或真人操作者**。

先同步 `intent`，再执行；无法保存意图时停止清理。之后补记 `completed` 或 `failed`。补记失败保留原意图，向服务日志写入不含私人字段的 `workspace-audit-incomplete`，不伪造完成、不覆盖主操作结果。失败可能发生在部分步骤完成后；研究记录删除完成不代表嵌套缓存清理成功，嵌套事件独立报告。

重置保留变更记录，备份一起保留。目前没有自动轮转期限，隐私政策已说明。**它不是不可篡改审计，不覆盖 SSH、管理员命令、直接文件操作或部署脚本。**

过期上传改为先保存元数据移除，再删除原件；保存失败恢复内存记录并保留原件。工作区快照同步临时文件、原子替换并同步目录。缓存过期保留研究记录；未更改 24 小时留存政策或已确认原件保护。

## 离线备份检查

`scripts/verify-backup.py` 使用 Python 3.11+ 标准库，要求独立保留的可信 SHA256，同一打开文件完成哈希与解析。

```bash
python3 scripts/verify-backup.py /private/backup.tar.gz --sha256 TRUSTED_SHA256
python3 scripts/verify-backup.py /private/backup.tar.gz --sha256 TRUSTED_SHA256 --extract-to /private/recovery-new
```

不指定目标时在临时目录检查并移除副本。指定目录必须不存在，父目录已存在且祖先没有符号链接；禁止固定生产数据、发行版和备份根目录。独占创建文件，不覆盖已有目录。默认限制 25 万条目、展开 20 GiB，并预检可用空间；可按实际预算调整。

预检拒绝绝对路径、路径穿越、软/硬链接、特殊文件、稀疏条目、重复路径和文件/目录冲突。检查 SQLite 完整性、外键和认证 schema 2，工作区归属、材料/上传双向关系、原件大小与 SHA256；仅输出数量。旧访客归档不自动转入账号。

失败可能留下新建的隔离目录，必须继续隔离，不能接入生产。工具不停止服务、不执行归档脚本、不加载环境配置、不更改线上目录。配置存在只说明随归档保留，**不证明生产密钥正确、所有流程可恢复或内容语义完整**；仍需隔离启动验收。不宣称支持任意历史格式。

## 实际验收

- `npm test`：1096 项通过，0 失败、0 取消；类型、构建与竞品研究记录检查通过。
- `tests/password-recovery.test.ts`：未配置与跨域拒绝、泛化响应、弱密码、过期/重复/并发令牌、旧会话撤销、两步验证和工作区保留。

- `node --import tsx scripts/browser-reliability-qa.mjs`：6 项浏览器检查、2 张桌面/390px 截图；实际找回、确认校验、重置、原账号登录、已登录状态打开链接、已用链接错误、无横向溢出与页面异常。无真实邮件/来源/模型调用。

浏览器回执在本机 `output/browser-qa/reliability/receipt.json`，截图同目录，忽略提交。全量测试后加强了恢复后的验证器登录断言，相关 11 项单独重跑通过。生产部署验收独立于本机结果。
