## 网站简介

析光（Prispect）从一家公司或一件待核事项开始。公开证据 Agent 核对年度利润、经营现金、相关附注和近期披露，给出有依据的观察与尚未解决的问题。外部用户可继续核对预付款，内部接手者可检查具体日期的现金计划。私有记录支持各自的条件测算；历史财务信号不填入当前现金或未来回款。

本项目参加学军中学「回响·48H 青年创造营」X-Ray 方向。原件现金桥核对明确的财务问题，公司研究 Agent 扩展公开数据分析。单一历史现金比例不等于整体评级；析光的透明财务筛选等级不属于评级机构信用等级、授信决策或投资建议。用户需求与付费意愿仍属于研究假设。

产品信息见[使用文档](https://prispect.com/docs)、[产品介绍](https://prispect.com/about)、[隐私政策](https://prispect.com/privacy)、[用户协议](https://prispect.com/terms)与[版权说明](https://prispect.com/copyright)。政策描述已实现的服务，不等于法律合规认证。联系邮箱：`lailai0x394@gmail.com`。

## 网站特性

🔐 **个人账号** — Better Auth 注册、头像和资料设置、密码强度检查、TOTP、一次性恢复码、通行密钥与会话管理。材料、核查和导出按用户归属访问。邮件验证和找回需要 SMTP；提供商未配置时明确返回不可用。

🏢 **企业工作区** — C 版将公司概览、年度与最新定期报告、同年度行业对比、公告聚合、企业资料/股东/新闻、覆盖和来源比对七个页面融入原有析光设计。企业问答通过右下角圆形助手打开小对话框；公司页面沿用当前企业和利润口径，其他页面可选择账号内已保存的企业。尚未载入企业时提供本地产品帮助与文档入口，不调用外部模型。登录后查询与保存，公众/管理者阅读视角和外部付款/内部交接目的独立保留。网页概览保留归母与合并利润口径，原件现金桥保持同年度合并净利润。新查询和企业问答统一使用已配置的服务端模型，不可用或失败时保留规则结果。参见[融合与验收记录](docs/version-c-integration.md)。 侧边栏已载入企业的记录可通过右侧 × 一键删除本次查询和问答，已采用材料保留；查询或分析进行中需等待完成。

📄 **核查摘要** — 公司查询默认打开简洁核查报告，先展示所选年度合并利润、经营现金、来源入口及后续材料。详细财务资料默认收起；七个公司页面、阅读视角、利润口径和私有核查工具继续保留。公开网页字段与已确认原件分别保存。原件报告也默认展示摘要，图表、解释和询证清单仍可通过报告栏目查看。

🗂️ **公开证据 Agent** — LangGraph 并行核对官方 A 股年报、相关附注与选定的近期公告原件。独立的审计意见检索保留原文、PDF 页码和范围线索，不给审计意见或公司评级。受限模型动作从公开候选 ID 中选择有限补查；规则提取金额并保留冲突。失败或取消的查询可在24小时内恢复，请求预算累计。候选经核对采用后才成为个人材料。 官方年报原件使用独立的100 MiB上限；用户上传和选定近期公告仍限25 MiB。近期公告读取共享45秒预算，未读完会明确提示覆盖不足。现金流补充表提取保留主体、年度、合并口径及单位依据，并使用PDF表格单元格定位，分别保留两年中已披露的金额。空白保持未知，核对差额会暂停现金桥。参见[真实公司算法回归记录](docs/algorithm-verification-2026-10-02.md)。

📊 **财务历史图表** — 与官方原件检索并行，匿名请求东方财富三张财务表，保留最多六个年度。交互图表比较利润与经营现金、收入与利润，以及货币资金与两项指定负债；选择年度查看精确金额、字段、取数时间与响应哈希。年报候选原件另行对照，缺值保持未知，网页字段不会自动采用为正式材料。

🧮 **可重算的财务处理** — JSON、CSV 与文本 PDF 预览、可编辑确认、期间/币种/口径检查、整数分精确计算，以及持久保存的报告和问题单。两期利润与经营现金变化保留两期来源引用和精确公式；同比要求上期基数为正，冲突时暂停比较。

🔎 **证据与决定版本** — 现金桥、原文页码与两种可能解释形成补件问题。组合规则保存成立、条件未全部满足或暂不能核对的状态，列出所需指标及有来源的缺口；组合卡可检验单项依据，并复制适合外部付款者或内部接手者的材料请求。付款底稿保留输入/证据版本、材料文本绑定及已知冲突。撤回直接依据会暂停依赖它的记录计算，保留无关事实与明确录入的假设。

🧪 **付款情景** — 外部比较本次拟付款后的未交付敞口与自设上限；内部按已列90天事件比较付款日期、事件余额、期末和条件下的付款/回款阈值。同日顺序、资料覆盖范围与改期可协商的假设明确保留；缺失输入保持未知。

🌐 **双语完整流程** — 中英文产品流程、使用文档与政策。语言按钮显示当前语言；外观支持自动、浅色、深色，并在下次访问时保留。材料、现金计划与头像可拖放，提供校验与重试。报告区分付款与接手重点，询证清单按依据排序并提示取件角色；HTML、JSON 和 Markdown 清单先预览再保存，保存的内容与预览快照相同。原文引用保留源语言。

⌨️ **工作区细节** — 顶栏搜索与 ⌘ K / Ctrl K 可跳转到当前账号的页面、已保存公司、报告和材料。列表筛选显示数量，Esc 可清除搜索，核查可排序，材料结果直接定位到对应记录。控件、空状态、加载占位和短暂过渡统一，并遵循减少动态效果设置。成功通知在悬停、聚焦或隐藏标签页时暂停；错误保留至手动关闭。导出预览提示下载已开始，不声称文件已保存到磁盘。

🧠 **公司研究 Agent** — 新公开快照自动开始有限研究：分页获取东方财富/新浪新闻与对应公司的公开股吧目录，再由模型选择财务、同行、主题检索与原文核对。最多保留 180 条去重新闻和 240 条公开帖子，实际正文节选与目录标题、摘要分别标注。帖子仍属未核实观点，转载不代表独立证实。用户可指定研究目标；真实步骤、失败、文本限制与资料覆盖可查看。六维判断把优势、风险、后续核查和判断变化条件关联到可检查的指标与来源。扩展公开资料的初稿另经一次模型调用，检查反向论据和来源归属；该阶段失败会提示。模型不能改写财务评级。未配置或输出无效时保留规则分析。参见[流程与方法](docs/company-research-agent.md)。

💹 **企业简报与行情快照** — 企业简报汇集主体资料，并尝试读取东方财富行情，保留精确价格、涨跌、市值与来源报价时间。缺失或受限字段保持不可用；取得的行情不保证实时，也不改变所选年度财务评级。

📐 **透明分析评级** — 所选年度合并口径的盈利、现金质量、偿付能力和营运资金等权计分，关键弱项限制整体评级；必要字段缺失或冲突时暂不评级。同行与事件分析提供独立背景。报告展示公式、阈值、资料覆盖和评级限制，单凭新闻标题不能认定不利事件。

🔬 **企业证据实验室** — 查看来源事实、计算、竞争解释与待补材料之间的联系。暂时撤回或恢复一条事实，只暂停依赖它的路径。首页实例使用已核对的原表调整与现金桥，公司网页快照使用年末余额变化，两种依据分别展示。本地试验不调用模型，也不改写已保存证据、报告或评级。参见[方法与操作示例](docs/evidence-lab.md)。

🧭 **挑战一个解释** — 围绕已保存公司的扩张备货、存货去化压力或回款压力，执行真实的定向公开检索与有限官方 PDF 阅读。已配置的模型整理带来源的支持、反向线索，并明确尚未取得的区分性材料。未配置时仍可执行固定公开补查并保留规则线索；失败不虚构结果或可信百分比。本地撤回状态与私有底稿不进入挑战载荷。

## 快速开始

使用 Node.js 22.12 或更新版本及 npm。访问本私有仓库需要授权。

```bash
git clone https://github.com/lailai0916/prispect.git
cd prispect
npm ci
npm run build
npm start
```

打开 `http://localhost:4317`，注册账号（密码8–128字符且不易猜测），输入公司或待核事项。新账号工作区为空。macOS 可以双击 `start.command`：缺依赖时安装，再构建并启动。开发使用 `npm run dev`，打开 `http://localhost:4318`。在其他端口使用通行密钥时，将 `APP_ORIGIN` 设置为浏览器实际来源；生产必须使用 HTTPS 和持久的 `BETTER_AUTH_SECRET`。

```bash
npm run check
npm run data:fetch
npm run data:samples
```

`check` 执行严格类型、金融/账号/API 测试、前端构建与格式检查。`data:fetch` 只下载清单中的公开报告并校验 SHA256，原始 PDF 不提交 Git。`data:samples` 生成结构化导入样例。扫描 PDF 和含糊表格需确认，不能虚构提取值。

财务金额与计算仍由规则处理。新建企业查询、企业问答和财报解释统一使用已配置的服务端模型，复制、恢复和重试也遵循这一策略；模型未配置、材料缺失或冲突、调用失败时保留规则结果并如实显示状态。模型只通过服务端 `.env` 配置，参考 `.env.example`；数据使用范围见隐私政策和使用文档。公司研究发送明确录入的研究目标与所选公开证据，包括带日期的新闻及公开讨论标题、摘要和实际取得的节选，企业问答发送问题及公开资料；财报解释发送已采用指标与短摘录，可能来自用户上传的财务材料。两者都不发送完整上传文件、私人事项说明、备注或现金计划。本地产品帮助不调用外部模型。私有 CSV/JSON 现金计划在浏览器解析，采用后是待保存的计划条件，不是经认证的记录。引用 ID 与数值校验不能证明语义正确。检索使用已配置的 A 股披露、东方财富财务/行情/新闻/股吧和新浪公开来源，未实现全网或 X 搜索，未接入须商业授权的工商数据服务。公开来源可能不可用；服务保留实际覆盖，不虚构缺失结果。

账号、会话与各用户底稿保存在 `CASHLENS_DATA_DIR`（默认 `.cashlens`）。保留完整目录和认证密钥，部署或恢复前阅读[部署与备份说明](docs/deployment.md)。公网域名为 [prispect.com](https://prispect.com)，域名迁移与新域验收独立于历史发布记录；发布验证和适用范围见[验收记录](docs/acceptance.md)。当前为单进程产品，未测量生产容量或实现多节点高可用。SMTP 尚未配置，界面明确显示邮箱验证不可用。手机号作为可编辑、可清空的资料展示信息保存，无需短信验证码，不用于登录或找回密码。

主分支 CI 通过后，经受限 SSH 入口自动部署；包含归档与源码完整性检查、一致性状态备份和构建资产核对。仅当前认证数据库兼容旧版时允许失败回退。参见[自动部署说明](docs/actions-deployment.md)。

参见[方案](docs/plan.md)、[方法与数据调研](docs/research.md)、[API 合同](docs/api.md)、[数据链路交接](docs/data-lineage.md)、[参考方案鉴别](docs/reference-data-review.md)、[AI 使用披露](docs/ai-usage.md)及[赛事提交要求](docs/submission-checklist.md)。私有仓库徽章可能无法显示。

## 项目结构

```bash
prispect/
├── data/                           # 核验样本输入与来源清单
├── deploy/                         # HTTPS 反向代理配置
├── docs/                           # 方法、证据、交付与部署资料
├── public/                         # 本地品牌资源
├── scripts/                        # 开发与来源获取工具
├── server/                         # 认证、隔离存储与处理接口
├── shared/                         # 前后端共享类型合同
├── src/                            # 双语 React 网站
├── tests/                          # 金融计算、账号与接口验证
├── compose.yml                     # 单服务器持久化容器配置
├── Dockerfile                      # 可选容器构建
├── package-lock.json               # 精确依赖锁定
├── package.json                    # 运行与验证命令
├── start.command                   # macOS 启动入口
├── tsconfig.json                   # 严格 TypeScript 配置
└── vite.config.ts                  # 前端构建与本地接口代理
```
