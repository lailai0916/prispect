## 网站简介

析光（Prispect）从一家公司或一件待核事项开始。公司查询先展示结构化年度财务、经营现金与有来源的规则观察；需要时仍可进入公开资料深度研究或年报原件核查。外部用户可继续核对预付款，内部接手者可检查具体日期的现金计划。私有记录支持各自的条件测算；历史财务信号不填入当前现金或未来回款。

当前公司研究支持 A 股。阅读默认采用归母利润，可切换合并利润；财务筛选与原件现金桥仍采用人民币年度合并口径。美股新研究暂不开放，当前账号的历史记录与已保存原件仍可查看。其他币种保留原金额与单位，不作汇率换算，也不重新标注为人民币。

银行、证券与保险公司已纳入公开财务取数和分析。程序按利润表返回的机构类型选择现金流量表与资产负债表；所有支持的企业使用相同的指标、阈值、评分与报告展示，按需模型分析也遵循相同规则；已取得金额、比例和依据正常展示，缺失字段不补零。详见[金融机构支持记录](docs/financial-institution-support-2026-10-03.md)。

本项目参加学军中学「回响·48H 青年创造营」X-Ray 方向。原件现金桥核对明确的财务问题，公司研究 Agent 扩展公开数据分析。单一历史现金比例不等于整体评级；析光的透明财务筛选等级不属于评级机构信用等级、授信决策或投资建议。用户需求与付费意愿仍属于研究假设。

[文档主页](https://prispect.com/docs)提供六篇文章：[关于析光](https://prispect.com/docs/about)、[使用指南](https://prispect.com/docs/guide)、[核查方法](https://prispect.com/docs/methodology)、[隐私政策](https://prispect.com/docs/privacy)、[用户协议](https://prispect.com/docs/terms)与[版权声明](https://prispect.com/docs/copyright)。旧文章地址与原使用文档的章节链接仍兼容。政策描述已实现的服务，不等于法律合规认证。联系邮箱：`lailai0x394@gmail.com`。

验证包括本机完整检查与浏览器交互回放；模型提供商验证和生产发布验收分别记录。具体范围、证据和发布准备见[重构方案与验收任务](docs/rebuild-plan.md)及[生产容量记录](docs/production-capacity-2026-10-03.md)。

[固定版本的竞品研究工程](docs/competitive-research/README.md)保存五仓库深入拆解、全量价值清单、方案比较、实施映射和前后验收，分别标记实时请求、缓存、合成夹具与提供商阻塞。本轮增加说法与依据逐项对照、经营名义与责任主体分离、相邻事项版本差异、付款条件反求、已知来源关系、受来源约束的研究框架、可选证据依赖练习与静态离线事项导出。这些机制不认证资料、不批准付款，也不把来源条数变成确信度。

## 网站特性

💾 **企业研究缓存** — 再次选择同一公司、年度、用途和研究模式时，直接打开本账号已有研究，不重复检索或调用模型。最多十二份公开快照保存在有容量上限的浏览器缓存中，重开页面可直接呈现，手动刷新前保留原取得日期。原件、私人问答和用户研究目标不缓存；删除、重置、退出和切换账号同步清理对应副本。 服务器还复用经过核验的匿名公开响应、按原件哈希绑定的官方 PDF 解析，以及完整同年度同行样本。助手回答仅在同一账号的问题、对话和资料版本完全一致时复用；明确补查与手动刷新重新执行。三个解释挑战分别保留有来源的结果，可点击“重新补查”。参见[资源缓存行为与验证](docs/resource-cache-2026-10-03.md)。

🔍 **依据核验与操作反馈** — 依据抽屉将已保存摘录对应到支撑字段，区分原文金额与计算指标；所选财务字段在同一抽屉展示两处来源的原值、口径和差额。付款暴露按需解释当前分支金额，编辑已保存事项的实际变更标记为待重算。研究等待或失败时可继续查看已取得资料及真实日期；按版本取消本轮公开研究保留来源与报告，迟到回调不能覆盖重试结果。助手建议先填入可编辑草稿，依赖练习区分漏选与多选，并展示真实依赖路径。这些改进融入既有动线；通用 PDF 原句精确定位及账号材料全文检索尚未实现。

🔐 **个人账号** — Better Auth 注册、头像和资料设置、密码强度检查、TOTP、一次性恢复码、通行密钥与会话管理。材料、核查和导出按用户归属访问。邮件验证和找回需要 SMTP；提供商未配置时明确返回不可用。

🏢 **企业工作区与导航** — “新建研究”下方直接显示研究报告、财务走势、行业对比、公告线索、扩展核查、数据覆盖、来源比对七项入口，不显示企业分组标题；统一助手仍保留在右下角。导航优先使用当前账号正在查看的企业，再使用最后创建的查询，不按记录更新时间排序。没有记录时，七项菜单保持显示但禁用，从“新建研究”建立记录。查询页显示最多三条最近研究，侧边栏“已载入企业”可打开本账号已有记录，不启动新的研究。旧 `/research` 链接跳转到 `/query`。旧公司、原件和私人核查链接继续兼容。

📄 **研究报告** — 研究报告展示年度利润、经营现金、历史资金与规则观察，保留精确计算与来源抽屉。默认归母利润，可通过同一控件切换合并利润；财务走势、行业对比、公告、扩展核查、覆盖与来源比对各有独立页面。已有深入判断、财务评级、证据实验室和原件确认仍可按需进入；网页字段不自动成为已采用原件。

📍 **连续核验** — 报告摘要的待核数量可展开同一份核查清单，每项复用已有依据入口。公司页目录标出当前章节；核验后返回报告时，同账号、年度及资料／分析快照内可继续原阅读位置。新范围重置，显式章节链接优先；阅读状态只留在页内内存，不改变报告、评级或证据。

🔎 **定向研究与问询** — 明确请求的深入研究在原预算内保留相关原句和反向线索，注明省略与重复引用。私有问题关联回复与原件，保存不可变版本；回复仍是待核验陈述。[有限模型对照](docs/research-depth-live-check.md)区分合成输入与真实调用。

📰 **来源阅读** — 已取得的新闻和公开讨论保留本地关键词、媒体、内容范围筛选、日期排序和分页；窄屏仍可读取所选来源。标题、摘要与实际取得的正文节选分别标明。筛选已保存资料不调用模型或公开来源。

🧭 **研究入口与问答** — 入口保留当前账号的输入草稿，确认匹配主体后创建研究。公开公司代码与简称通过预载目录快速匹配，未命中时有限远程补查；回车立即匹配，多个候选保留选择。右下角析光助手通过同一段对话回答已研究企业、产品使用和政策细节，自动接续企业上下文，按需补查公开资料，并引用实际企业来源或正式产品文档。未登录时仅检索产品文档，不调用模型或访问私人工作区；登录后的回答使用已配置模型，失败时保留真实规则回答或文档原文。

🗂️ **原件核查兼容** — 明确进入原件核查时，仍可使用 LangGraph 核对官方 A 股年报、附注与选定公告原件。规则提取金额，保留缺失与冲突；候选经确认采用后才成为个人材料。默认公司查询不启动这一流程或下载 PDF。参见[真实公司算法回归记录](docs/algorithm-verification-2026-10-02.md)。

📊 **财务走势与行业对比** — 东方财富结构化财务接口保留最多六个年度。四组主题各有四张指标卡片，可通过「全部图表」浏览；金额柱图、比率折线与负债明细哑铃图沿用克制配色。利润与经营现金共用金额尺度，每张卡片可展开逐年精确数值与来源。财务走势与行业对比共享选定年度，切换年份或展示方式不发起请求。打开图表页仅按顺序补齐尚未取得且未失败的同行年度，再次打开复用已保存样本和失败状态；明确刷新绕过共享缓存，失败保留原取得日期和上次资料。行业可切换对比图表、同行分布和数据明细，每张卡片打开对应年度指标的分布。缺失与冲突保持未知，网页字段不会自动采用为正式材料。参见[F 主流程记录](docs/f-core-mainline-2026-10-03.md)。

🧮 **可重算的财务处理** — JSON、CSV 与文本 PDF 预览、可编辑确认、期间/币种/口径检查、整数分精确计算，以及持久保存的报告和问题单。两期利润与经营现金变化保留两期来源引用和精确公式；同比要求上期基数为正，冲突时暂停比较。原件报告的输入或币种冲突表示材料待核对，暂停相关解读，不直接认定企业风险或形成公司评级。公开新闻与讨论分析沿用企业研究记录，打开原件报告不会另发口碑 RSS 查询。

🔎 **证据与决定版本** — 现金桥、原文页码与两种可能解释形成补件问题。组合规则保存成立、条件未全部满足或暂不能核对的状态，列出所需指标及有来源的缺口；组合卡可检验单项依据，并复制适合外部付款者或内部接手者的材料请求。付款底稿保留输入/证据版本、材料文本绑定及已知冲突。撤回直接依据会暂停依赖它的记录计算，保留无关事实与明确录入的假设。

🧪 **付款情景** — 外部比较本次拟付款后的未交付敞口与自设上限；内部按已列90天事件比较付款日期、事件余额、期末和条件下的付款/回款阈值。同日顺序、资料覆盖范围与改期可协商的假设明确保留；缺失输入保持未知。

🌐 **双语完整流程** — 中英文产品流程、使用文档与政策。语言按钮显示当前语言；外观在打开网页和系统主题变化时自动跟随系统，可随时一键切换深浅色。材料、现金计划与头像可拖放，提供校验与重试。报告区分付款与接手重点，询证清单按依据排序并提示取件角色；HTML、JSON 和 Markdown 清单先预览再保存，保存的内容与预览快照相同。原文引用保留源语言。

⌨️ **工作区细节** — 顶栏搜索与 ⌘ K / Ctrl K 可跳转到当前账号的页面、已保存公司、报告和材料。列表筛选显示数量，Esc 可清除搜索，核查可排序，材料结果直接定位到对应记录。控件、空状态、加载占位和短暂过渡统一，并遵循减少动态效果设置。悬停链接或键盘聚焦时预载页面模块；切页保留当前内容，目标就绪后再切换。研究统计与输入区在读取记录时保持位置，切换语言不清空已取得记录。原件核查复用企业页面已读取的所选记录；加载不闪现新建查询表单或重复的历史提示，模块等待使用对应原件内容的占位。图表切换与窗口缩放保持绘图区高度；切换语言继续已开始的同行读取，资料刷新不重复跳回已定位章节。后退与前进在内容就绪后恢复该次访问的阅读位置，用户主动滚动优先。同一研究的公开资料更新保留筛选、所选来源和阅读位置；点击当前页签保留选择，来源被移除时关闭抽屉并归还列表焦点。工作区刷新失败时，仅在确认仍为同一账号后保留已读内容并提供只读重试；换账号或会话失效仍隐藏旧工作区。成功通知在悬停、聚焦或隐藏标签页时暂停；错误保留至手动关闭。导出预览提示下载已开始，不声称文件已保存到磁盘。

🧠 **按需深入研究** — 明确请求深入研究时，保留有限的东方财富／新浪新闻、公开股吧资料，以及模型选择的财务、同行和原文核对。真实步骤、来源覆盖、失败与摘录限制可查看，模型不能改写财务评级；未配置或输出无效时保留规则分析。这一流程与默认结构化财务查询分开。参见[流程与方法](docs/company-research-agent.md)。

💹 **主体资料与行情快照** — 主体与业务资料、东方财富行情快照继续可查，不重复公司报告里的判断。价格、涨跌、市值和来源报价时间保留源精度。缺失或受限字段保持不可用；取得的行情不保证实时，也不改变所选年度财务评级。

📐 **透明分析评级** — 所选年度合并口径的盈利、现金质量、偿付能力和营运资金等权计分，关键弱项限制整体评级；必要字段缺失或冲突时完整评级保留 NR。已有独立有效维度时，按已观察分数均值和相同弱项限制给出只读的暂定评级，标明覆盖范围，不改写保存的完整评级。同行与事件分析提供独立背景。报告可核对公式与来源，完整评级规则见核查方法；单凭新闻标题不能认定不利事件。

🔬 **企业证据实验室** — 查看来源事实、计算、竞争解释与待补材料之间的联系。暂时撤回或恢复一条事实，只暂停依赖它的路径。公司网页快照使用年末余额变化。本地试验不调用模型，也不改写已保存证据、报告或评级。参见[方法与操作示例](docs/evidence-lab.md)。

🧭 **挑战一个解释** — 围绕已保存公司的扩张备货、存货去化压力或回款压力，执行真实的定向公开检索与有限官方 PDF 阅读。已配置的模型整理带来源的支持、反向线索，并明确尚未取得的区分性材料。未配置时仍可执行固定公开补查并保留规则线索；失败不虚构结果或可信百分比。本地撤回状态与私有底稿不进入挑战载荷。

🔎 **公开首页** — 桌面采用左侧文案、右侧滚动证据展示，窄屏上下排列。原生滚动驱动一条 GSAP 时间轴，连接历史发现、年报原件裁片、带符号的现金桥与待检验解释。首屏与结尾统一通过「试一试」进入登录页；登录后保留现有研究工作台与 StartInput。CSS 变换、可访问的 SVG 和装饰性的 OpticalField 背景负责展示，不使用 Three.js 或 WebGL。减弱动效和短屏保留完整静态阅读流程。中英文保留同一份原始金额、全部 13 项分组明细与材料尚未取得的边界。见[首页实现说明](docs/cinematic-home.md)。

## 快速开始

使用 Node.js 22.12 或更新版本及 npm。访问本私有仓库需要授权。

```bash
git clone https://github.com/lailai0916/prispect.git
cd prispect
npm ci
npm run build
npm start
```

打开 `http://localhost:4317`，注册账号（密码8–128字符且不易猜测），输入公司或待核事项。新账号工作区为空。macOS 可以双击 `start.command`：缺依赖时安装，再构建并启动。开发使用 `npm run dev`，打开 `http://localhost:4318`。在其他端口使用通行密钥时，将 `APP_ORIGIN` 设置为浏览器实际来源；生产必须使用 HTTPS 和持久的 `BETTER_AUTH_SECRET`。

```bash
npm run check
npm run data:fetch
npm run data:samples
```

`check` 执行严格类型、金融/账号/API 测试、前端构建与格式检查。`data:fetch` 只下载清单中的公开报告并校验 SHA256，原始 PDF 不提交 Git。`data:samples` 生成结构化导入样例。扫描 PDF 和含糊表格需确认，不能虚构提取值。

财务金额与计算仍由规则处理。新建公司查询默认采用 `researchMode=financial`，通过官方主体确认与结构化公开接口取得资料，不自动调用模型或下载 PDF。明确请求的 `deep` 研究、登录后的助手问答和财报解释保留已配置的服务端模型流程；复制、重试与恢复保留所选模式，旧记录继续兼容。模型未配置、资料冲突或调用失败时保留真实规则结果。模型仅通过服务端 `.env` 配置，载荷范围见隐私政策。公司模型只使用允许的公开证据，不接收完整上传文件、私人事项说明、备注或现金计划；未登录的文档帮助不调用模型。私人 CSV/JSON 计划仍属于草稿条件，引用与数值校验不证明语义正确；公开来源不可用时保留实际覆盖。

账号、会话与各用户底稿保存在 `CASHLENS_DATA_DIR`（默认 `.cashlens`）。保留完整目录和认证密钥，部署或恢复前阅读[部署与备份说明](docs/deployment.md)。公网域名为 [prispect.com](https://prispect.com)，域名迁移与新域验收独立于历史发布记录；发布验证和适用范围见[验收记录](docs/acceptance.md)。当前为单进程产品，未测量生产容量或实现多节点高可用。SMTP 尚未配置，界面明确显示邮箱验证不可用。手机号作为可编辑、可清空的资料展示信息保存，无需短信验证码，不用于登录或找回密码。

主分支 CI 通过后，经受限 SSH 入口自动部署；包含归档与源码完整性检查、一致性状态备份和构建资产核对。新包保留最近三个通过 main push CI 的祖先构建的 hash 前端资源，让更新前已打开的浏览器继续加载对应页面；入口 HTML 保持当前版本，窗口外的旧客户端或回滚后可能需要重新加载。仅当前认证数据库兼容旧版时允许失败回退。参见[自动部署说明](docs/actions-deployment.md)。

参见[方案](docs/plan.md)、[方法与数据调研](docs/research.md)、[API 合同](docs/api.md)、[数据链路交接](docs/data-lineage.md)、[参考方案鉴别](docs/reference-data-review.md)、[AI 使用披露](docs/ai-usage.md)及[赛事提交要求](docs/submission-checklist.md)。私有仓库徽章可能无法显示。

可复现本机演练：先运行 `npm run build`，再运行 `node --import tsx scripts/serve-research-demo.ts`，打开输出的本机地址，注册演练账号并搜索 `601234`。演练使用明确标记的合成企业数据、新建临时工作区和规则分析，不查询公开来源或调用模型；拒绝载入非空工作区，也拒绝生产模式。两条演示路线和验收边界见[完整流程验收](docs/research-flow-acceptance-2026-10-03.md)。
